# 封面制作：短标题、人物与交付

完整对局默认交付带个性化短标题的横版封面。本流程可由任意 AI agent 或真人执行：整理素材 → 写好提示词 → 使用 AI 生图工具 → 核对 → 保存交付。先完成可复制的输入材料；生图可由 agent 调用工具，也可由真人在生图产品中操作。离线 `video:make` 负责视频流水线，封面按以下步骤单独完成。

## 从本局选择画面

先读 `plan.cast` 和已经审核的剧情节点，确定最值得呈现的真实冲突、对应人物与身份。真人参局的宣传点须按座位控制方式核对；角色插画只代表游戏席位。封面可以采用带情绪的宣传文案，不能把新编文字标成玩家原话，也不能虚构对局结果。

查看当前主题人物图集，记录具体行列或人物裁图；同时查看一张本局画面抽帧作为颜色与世界风格参考。提示词分别说明人物参考和场景参考的用途，保留发色、眼镜、辫子、服饰等辨识特征。选择一到两位主要人物通常更适合手机缩略图，构图可重新绘制。

封面短标题可独立于 `publish-copy.md` 的完整标题，用一到两行突出看点；结合本局情绪选择手写、漫画笔刷等个性化字体，明确给出逐字文案。人物脸部、核心道具和标题要有清楚层次。默认接近 16:9 的横版构图，重要文字留出安全边距；用户指定平台尺寸时以其要求为准。

## 先写好可复制的生图提示词

在本局制作目录的 `output/cover-prompt.md` 写入完整提示词和参考图片清单，任何人都能据此继续制作。用本局实际内容填完下面的模板，最终记录中不保留待填项：

```text
用途：狼人杀对局视频封面，横版约 16:9，适合手机缩略图观看。
本局真实看点：[用一两句说明冲突、相关席位的真实身份与结果]。
整体风格：[当前人物图集与成片的风格、色调、背景主题]。

参考图 A：[人物图集或裁图文件名]。
使用其中[第几行第几列]的[人物一]：[发色、眼镜、服饰等关键特征]；
使用其中[第几行第几列]的[人物二]：[关键特征]。
保留人物辨识特征，重新绘制适合封面的动作与表情。
参考图 B：[本局画面抽帧文件名]，用于场景和颜色参考。

构图：[人物左右位置、表情、代表本局冲突的道具、背景]。
人脸清楚，人物和标题层次分明，重要元素与画面边缘留有余量。

画面中文字必须逐字写为：
第一行：[简短标题上句]
第二行：[简短标题下句；如只需一行则删除此项]
小标签：[已核对的真人／AI等宣传标签；不需要则删除此项]
字体：[与剧情气氛相符的手写／漫画笔刷等个性化字体]，
大字、强对比、清楚描边，缩小后仍可辨认；文字避开人物脸部。
仅包含以上文字，不添加游戏界面、字幕框、额外标语或水印。
```

提示词内的文件名须对应实际可上传的图片；同时在记录中列出本机路径和人物行列，交给其他人时附上这些文件。只交一段依赖上一段聊天的描述，无法保证他人复现相近画面。

## 使用 AI 生图工具生成

选择当前可用且在授权范围内的 AI 文生图工具。支持参考图的工具更容易保持本局人物一致：

1. 新建横版图片任务，设置约 16:9 的比例；平台有封面尺寸要求时使用其指定尺寸。
2. 复制已填写完整的提示词，上传清单中的人物与场景参考图；按实际工具说明配置参考用途。
3. 生成后下载原图，按下一节检查；有问题时保留旧版，调整具体有误的文字、人物或构图后再生成。

真人可以直接在生图产品的网页或应用中完成上述操作；具备已授权接口的 agent 可提交同样的提示词与参考图。没有内置生图能力的 agent 先准备这份完整材料，交给可用的生图工具或真人执行，再导入结果继续检查。通用流程不依赖任何专属工具名称或调用协议。

若工具仅支持纯文生图，在提示词中完整描述人物外观并逐项对照参考图。若生成的中文字反复不准确，可让生图工具留出标题区，再在图片编辑器中用粗手写／笔刷字体、描边和阴影添加准确文字，导出完整封面。仍按相同的人物、文字和可读性标准验收。

## 检查生成结果

打开生成结果检查：

- 文案逐字正确，字体虽有个性仍容易辨认，缩到手机缩略图大小后主标题清楚。
- 角色外观和实际身份对应，真人／AI标签与本局记录一致。
- 人脸、手部、道具完整，标题不挡表情，边缘文字不易被裁切。
- 构图、颜色和成片主题相符，检查实际像素尺寸，不把提示词中的目标尺寸写成实测结果。

首次完整封面可直接作为样品展示，用户未要求单独确认时按授权继续完成其余交付。

## 保存与交付

将选定图片保存或导出为 PNG，放到**本局制作目录**的 `output/cover.png`，保留生成工具的原始文件。在已写好的 `output/cover-prompt.md` 中补全最终短标题、最终提示词、参考素材路径与人物位置、使用的生成工具、实际尺寸，以及有无后加字体。已有 `cover.png` 需要替换时先保留旧版。

最终核对同一 `output` 中的成片、封面、`publish-copy.md` 和封面制作记录，展示或链接成品封面。视频验证报告只证明其实际执行的检查；封面仍需上述视觉核对。具体房间的图片、真实对局材料和制作缓存留在忽略的数据目录，GitHub 技能包只包含通用流程与工具。

## 可选方式：Codex 内置生图

Codex 会话提供内置图像生成能力时，可使用该能力执行上面的生成步骤；若同时提供 `imagegen` skill，先阅读它的工具使用说明。查看人物和场景参考图后，将同一份完整提示词及参考图传入生成工具，生成后把原图复制到 `output/cover.png`，按通用标准检查并补全制作记录。

此节仅说明一种可选工具接法。其他 agent 和真人直接使用前面的通用流程，无需安装 Codex 或具备其内置工具。
