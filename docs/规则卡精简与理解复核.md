# 规则卡精简与理解复核

更新：2026-11-02。本轮修改规则说明、模型提示和翻译，不改变引擎的角色、行动许可、结算或信息受众。

## 规则取舍

- 公布出局后停止常规发言、投票和夜间技能；完成法官明确授权的遗言、死亡触发技能、警徽处理后旁观。不能简单写成“死亡后任何行动都禁止”，否则会与猎人开枪、遗言和警徽流程冲突。
- 夜间攻击和毒药在所有夜间行动完成后统一结算；被选择为攻击目标不会立即取消其本夜尚未完成的行动。
- 首夜先竞选的配置中，未公布的夜间受害者仍按当前资格参加竞选，不能以参与资格反推其存活。
- 警长是任何阵营都可竞选的职务，当选不证明是好人，警徽不改变身份、阵营或技能。

查验说明中的“出局或移交警徽不会自动公开或转交查验记录”来自 `fed8daf` 的信息边界整理。该次整理没有新增真实模型问答；未找到对应“死亡或交徽自动公开查验”的具体幻觉实例，不能将其说成针对已证实幻觉的修补。有关被查验者是否收到通知的既往样本是另一个问题，见 [查验通知与信息边界](查验通知与信息边界.md)。

此次移除查验段落与警徽的重复关联，在通用警徽条款保留“移交不转移技能或私密记录”，并在出局总则和模型目标段明确行动边界。它不表示预言家天然拥有警徽，也不改变终局公开复盘。

## 精简方式和范围

参考工作区 Cursor 草稿后，按实际规则分支核对并精简公共说明、狼队投刀、守卫、女巫、觉醒隐狼及竞选流程。警长规则拆为竞选、投票和竞选自爆三段；角色仍保留 `· 身份名：` 格式，供网页和离线视频解析。

## 真实模型理解复核

使用用户本轮授权的项目 Token Plan 入口。最初选择的已保存 `qwen3.6-plus` 三次请求均返回 `403 AccessDenied.Unpurchased`，没有获得回答；随后在同一 Token Plan 入口显式改选项目已有的 `qwen3.8-flash`，不修改模型库、密钥或计费入口。

`qwen3.8-flash` 使用 Chat Completions、温度 0.2、`thinkingMode=off`，分别进行中文标准十二人、英文标准十二人、日文镜隐迷踪三个独立请求。输入为合成席位的实际系统规则与身份说明，以及规则理解问题；不推进真实房间，不发送历史玩家对话或其他座位私密数据。

三次共 28 个小问，人工核对回答与引擎一致，覆盖：出局后不能继续查验、交徽不转移查验、狼人可竞选警长、警长不证明阵营、含毒不能开枪、合法死亡技能与遗言例外、首夜通报前竞选资格、夜间统一结算、被查验者不获通知，以及隐狼模仿后的表面役职与真实阵营。

英文回答提出了遗言时序、警徽操作表达、猎枪遗言资格和空守重置的文案疑问；其具体答案仍正确。对应条款和合法操作由规则配置、法官菜单与引擎确定，本轮未据这几个主观疑问继续堆叠提示词。

三次成功请求合计输入 9706、输出 1169 token；失败请求不计入此值。问题和回答记录保存在忽略的数据目录，公开文档只记录方法与结果。这是小样本理解复核，没有前后对照，不能证明幻觉已经消失，也不等于完整真实对局验收。

## 集成验收

本轮 51 个测试文件、456 项测试通过，TypeScript 类型检查和网页生产构建通过。回归包括配置分支、死亡行动许可、公告时序、信息投影、三协议错误语言和视频规则提取。

主会话使用隔离的合成模型与未开局房间检查了列表折叠、分页、删除末页后的页码回退，以及真人默认昵称在切换控制者、进入、准备和刷新后的保留。另补了旧房间空昵称回退，但没有复现用户此前昵称丢失的确切触发路径，不能将回退防护描述成已经确认该根因。
