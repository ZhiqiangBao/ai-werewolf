## 语音输入

- [ ] 设计统一语音输入入口，可选择系统听写引导、在线 ASR 或本地 ASR 服务。
- [ ] 评估各平台实际提供的启动能力。普通网页不能假设有统一的系统听写唤起接口；缺少支持时给出系统快捷键说明，不假装已经启动录音。
- [ ] 在线 ASR 与本地 ASR 使用可替换接口，明确语言、音频格式、取消、失败处理与配置方式；服务密钥留在服务端。
- [ ] 识别结果写入当前席位自己的发言草稿，由玩家检查后手动提交，沿用现有行动校验；处理朗读时的回录、重复识别和切换轮次。

当前仅在 [README](../README.md#voice-input) 提供 Windows、macOS 与 Linux 的系统／输入法听写操作说明，没有项目录音按钮，也没有新增 ASR 服务。

## 邀请短链

- [ ] 如完整链接与二维码仍不便分享，增加本服务内的短链映射；使用不可猜测的凭证，保持房主、座位与观战权限分离，并设计到期／撤销和存档兼容。
- [ ] 保留完整邀请链接和本地二维码，不依赖外部短链平台转存房间凭证。

当前已提供网页本地生成的座位／观战邀请二维码，默认服务支持局域网访问，并自动选择局域网分享地址；可切换网卡或手动填写网址。二维码与复制邀请使用相同的分享地址与权限，不替代网络连通配置。尚未进行真实手机扫码或第二台局域网设备验收。
