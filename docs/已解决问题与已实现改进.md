### ARCH-ROOM-MANAGER：拆分 RoomManager 职责（已解决）

- **原优先级与完成日期：** P1，2026-11-02。
- **原问题与边界：** `RoomManager` 同时承担候场／凭证、运行调度、视图通知、保存审计及超时。按用户提供的方案在 `packages/session` 内拆分，保持公开接口、行动、计时和信息权限语义。
- **实现结果：** `RoomManager` 由 1457 行缩至 187 行，仅保留兼容入口、依赖装配和房间生命周期编排；新增 `RoomLobbyService`、`RoomRuntimeService`、`RoomViewService` 与 `RoomPersistence`，沿用 `ModelLibrary` 和 `RoomStore`。核对全部 24 个公开实例方法与 28 个存档字段，字段所有权具有穷尽类型约束；各房间仍共享唯一一份 `RoomRecord`，调度、订阅和保存状态分别由所属服务持有。业务服务无反向调用完整 `RoomManager`，本地依赖无循环。
- **兼容处理：** 保留 `ApiFailure` 构造器身份及原导出路径；保留引擎写入→截止时间→取消失效行动→安排保存→授权通知的顺序、300ms 合并保存、80ms 思考节流、结束思考立即通知、逐事件整波旁听，以及逐房间取消后落盘的退出顺序。引擎规则、协议适配、缓存策略和存档模式均未修改。
- **当时验证：** 56 个测试文件、474 项测试全部通过，TypeScript 检查与网页生产构建通过。四组固定基准对照由重构前提交 `ea8e7f7` 生成，覆盖新旧计时下真人视角／通知和完整模拟 AI 对局的请求、重试、线程、审计、事件与行动；新增自爆／暂停／超时／重复提交、单推进循环、保存节流、错误类身份、依赖边界及多房间退出回归。三协议本机 HTTP 模拟服务分别验证旁听、正式行动、无效工具重试、原生工具回执、暂停重载与跨席隔离；真实 HTTP/SSE 回归通过。

### BUG-AGENT-NAME：修复 agent 入座时覆盖人物默认昵称（已解决）

- **完成日期：** 2026-11-02。
- **根因与修复：** 独立补充客户端 `D:/werewolf-agent/player.mjs` 在未提供 `--name` 时仍向 `participate` 发送 `${seat}号`，覆盖服务端房间昵称。修复后省略 `--name` 只发送 `{ ready: true }`，显式名称才提交 `name`；无效名称会在发起网络入座或写席位文件前拒绝。
- **代码指纹：** 修复版 SHA-256 `3b66f507506168a088e2d09e1666830e0677c40728ab254137a6939ebd8e9072`；原版 `bf7baa446b9cd15c61b6458b50e5129c82441ed3df73018e42be8e82a1e010e2`。
- **当时验证：** 外部补充项目的最终源码运行 `node --test test/player-join.test.mjs` 5/5 通过，覆盖默认名、房主自定义名保留、显式更名、空值和缺参拒绝。真正 Codex CLI（`gpt-6-luna`、`xhigh`）在原版和候选修复的四个隔离、未开局席位执行 join/status，API 观察到原版默认名变为 `1号`、候选保留默认名、显式名称生效且房主自定义名不变；均为 `ready=true`。随后将同一有效入座逻辑落到原件，并前移无效名称的参数校验。
- **证据边界：** 未进行完整对局验收，未操作真实席位。该客户端仍是本机独立补充项目，修复尚未单独发布或进入 Git；此归档只记录当前本机修复和验证，不代表发布交付完成。
