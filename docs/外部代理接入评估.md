# 外部代理接入评估

更新：2026-11-02。用户提出的第六条本轮**仅作评估，未实施**；没有新增原生 agent 接口，也没有修改外部客户端或启动真实代理对局。

## 评估范围和建议

本机用户提到的 `D:/were-wolf` 不存在。经只读核对，现有真人席位外部客户端位于 `D:/werewolf-agent`：其根目录 `AGENTS.md` 引导代理使用 `player.mjs join/wait/act`，脚本使用席位凭证访问本项目接口。评估只读了该目录的公共说明和脚本，未读取座位目录、凭证或实际唤醒上下文；该本机路径不是本仓库的安装路径或发布依赖。

建议近期继续使用**真人席位 API 加外部程序唤醒**，先解决语言下发和客户端体验。这个路径复用已有座位凭证、受众投影、行动许可和引擎裁决，不需要为当前问题引入另一套接入流程。它仍依赖外部代理进程遵循指令、管理每席上下文和及时响应，不能把服务端语言字段视为模型一定会遵守的保证。

未来若确有多个代理框架需要统一对接、稳定消费机器可读事件、明确断线恢复及重复提交语义，或需要独立的代理生命周期和运维能力，可以再评估原生 agent 接口。新接口需要承担版本兼容、凭证与席位绑定、状态恢复和信息隔离的设计与维护成本；它不会自动修复外部提示词或模型的语言选择。本轮不承诺实现时间或自动切换语言。

## 现有链路与语言缺口

- 服务端的座位视图包含房间及投影的 `locale`、当前规则卡、本席身份与附录、按受众过滤的事件、当前任务、合法工具、决策标识和截止时间；见 [协议类型](../packages/protocol/src/index.ts) 与 [座位投影](../packages/engine/src/projection.ts)。开局前可通过房间摘要获取语言与规则卡，开局后使用座位投影。
- [HTTP 路由](../apps/server/src/main.ts) 提供 `view`、`stream`、`act` 等入口；[会话管理](../packages/session/src/manager.ts) 对提交检查座位凭证、真人控制、暂停状态和决策标识，再交由引擎校验。外部客户端现有 `wait` 使用推送通知和轮询，在变化后拉取视图；`act` 依据当前任务或即时行动窗口提交。
- 内置 AI 的 [提示词构建](../packages/llm/src/prompt.ts) 明确注入对局语言、规则及本席身份，并由会话管理同步到内置模型线程。外部代理作为真人座位接入时，`view` 返回的是座位投影，不会自动获得这段内置 AI 系统提示。
- 本机 `D:/werewolf-agent/player.mjs` 的 `cmdWait` 读取 `view`，但当前不读取或输出 `room.locale`、`projection.locale`；事件、身份、目标、工具说明与操作指引用了固定中文包装。完整规则文件和身份附录也不是每次唤醒都重新注入。根 `AGENTS.md` 当前要求从规则卡和公告判断语言，遇到不一致或混合语言时考虑公告与其他玩家的话，因此不能替代明确的对局语言字段。

这些事实表明英文局存在语言上下文缺口，并为中文输出提供了可能的解释。由于本轮未检查实际代理的系统提示、私有笔记或运行记录，也未启动实局，不能断言某次中文发言的唯一原因或声称修复已经验证。

## 后续可行方案与验收

在不改变服务端规则的前提下，可由外部客户端在每次 `wait`／`status` 和代理唤醒时提供 `projection.locale ?? room.locale ?? 'zh-CN'`，明确公开发言、狼队密谈、退水发言和遗言采用该语言。规则、身份和工具许可仍取自当前座位投影；玩家原话作为引用原样保留，不从玩家消息、聊天界面语言或旧局笔记推断对局语言。实际唤醒器如何接收和注入该字段，仍需结合其实现验证；仅修改本仓库的内置模型提示不能完成这一步。

若以后评估原生接口，最小契约应考虑：单席独立凭证；版本化的受权座位快照，包含语言、规则、本席身份、可见事件游标、当前任务／即时工具、决策标识、截止时间和行动开放时间；通知断线后的重拉与去重；以及重复、过期、暂停和未开放提交的明确结果。不得向外部代理提供上帝信息、其他座位私密上下文或可推断隐藏事件数量的全局序号。

后续验收应使用合成房间与模拟代理，检查英文和日文的公开发言与狼聊、旧档中文默认、每次唤醒确实收到语言字段、规则与工具参数不被改写，以及断线重连、重复提交、过期决策、暂停和超时。还需验证跨席与观战信息边界；语言提示的遵循情况应通过实际代理输出单独观察，不把提示词存在等同于输出必然正确。
