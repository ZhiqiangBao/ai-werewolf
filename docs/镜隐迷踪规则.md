# 十二人镜隐迷踪

更新：2026-11-01。项目版型 ID 为 mirror12，规则版本 presetVersion=1。

## 配置与依据

狼人阵营：三名普通狼人、一名觉醒隐狼。好人阵营：魔镜少女、女巫、猎人、守卫、四名平民。默认闭眼局、屠边、竞选警长，女巫不可自救；开局页允许调整的通用选项以本局规则卡为准。

[官方上线介绍](https://langrensha.com/news/official/20231113/26904_1119726.html)用于核对原版角色组合与模仿的基本时点。本文将项目采用的完整边界明确列出；一次额外爪击的保留、增强守护与同守同救、学习夜天亮开枪等以以下固定口径和测试为准。它们不代表该新闻稿逐项说明了全部判例。原版角色问答可对照[觉醒隐狼资料](https://moegirl.uk/觉醒隐狼)。本版没有加入增强变体中的双毒、白天自爆带人或白天无敌守护。

## 魔镜少女

每夜查验一名其他存活玩家，获知具体身份表现，不能重复查验同一玩家。无未查验目标时跳过。查验结果只给查验者和上帝，记录保存查验发生时的结果。法官不向被查验者通知查验行为或结果，未收到通知不代表没有被查验；隐狼复制魔镜查验时也遵守相同边界。

觉醒隐狼尚未模仿时显示「觉醒隐狼」；模仿后立即显示模仿身份。结果不额外透露真实阵营、能力资源或技能目标。普通预言家在自定义组合中查验觉醒隐狼时显示好人。

## 觉醒隐狼

真实底牌与胜负阵营始终保持觉醒隐狼、狼人阵营。它与普通狼人互不知晓身份，不参与普通狼队密谈，不能自爆；继承刀权也不补发队友资料。

从第 1 夜起，每晚模仿阶段均可选择模仿一名其他存活玩家或暂不模仿，整局只能成功一次。模仿立即获知目标真实角色并改变自己的具体身份查验表现，目标不会收到通知。技能在学习当夜结束后获得，夜间主动技能从下一夜可用。原角色与复制者的库存、查验及守护记录相互独立。

| 模仿对象 | 获得的能力 |
| --- | --- |
| 平民 | 无主动技能，保留平民的查验表现。 |
| 魔镜少女 | 每夜精确查验，不能查自己或重复查验；不读取源魔镜的历史。 |
| 女巫 | 独立的一瓶毒药，没有解药；不复制源女巫已用药的状态。不能毒自己。 |
| 守卫 | 独立的增强守护，可自守、不可连守，可空守；同时抵挡狼刀和毒药。空守解除连续守护限制。 |
| 猎人 | 获得后出局按猎人死因规则处理；学习夜结束、天亮中刀时可以开枪，含毒死因不可开枪。 |
| 普通狼人 | 获得一次性额外爪击，须技能启用且继承刀权后才能使用，可以保留至以后。 |

增强守护不挡白天放逐与猎枪。增强守护和解药同时作用于狼刀目标时，仍按本局同守同救规则结算；其中毒药攻击可被增强守护独立挡住。额外爪击按狼刀结算，可被守护或作用于同一目标的解药挡住。

其他狼人全部出局后，隐狼从下一夜继承每夜一把普通狼刀。最后一名小狼夜间死亡时，本夜不补刀。继承狼刀在女巫之前提交，模仿技能另开一个独立决策；同夜可以分别选择普通狼刀和已启用的复制技能。

复制猎人开枪时仅公开「猎人」的表面身份，隐藏真实狼身份；放弃是否翻牌沿用猎人规则。本人仍知道自己的真实身份，上帝仍见真底牌，正常终局复盘公开真实身份。警徽和遗言继续走统一死亡职责。

## 夜间时序

觉醒隐狼模仿 → 守卫 → 普通狼人密谈与落刀 → 隐狼继承狼刀 → 魔镜少女 → 女巫 → 隐狼已启用的模仿技能 → 夜间结算与能力启用 → 天亮。

没有合法行动者的步骤直接跳过，外部座位只看到「夜晚」，不会看到谁正在使用哪种技能。死亡、胜负、警徽和遗言继续由公共流程处理。

## 实现与兼容

- PlayerState.role 保留真实身份；RoleModule.inspectRole 单独决定具体查验表现，revealedAs 记录技能公开的表面身份。
- 复制状态使用带 kind 的类型联合，记录来源、学习夜、主动技能启用夜、库存与刀权；不写回源角色的资源。
- 夜间扩展使用 nightPhases、nightStart、afterNight，保留原 nightPhase 声明的兼容性。
- 每个隐狼开局获得固定的潜在技能工具目录；当前阶段、启用时点和资源只裁剪当轮菜单。复制不改系统提示或工具 Schema，私密事件追加到该席上下文。
- mirror12 是新增预设，不替换 standard12、classic9、idiot12；旧房间继续使用已保存的身份、规则值和工具版本。
- v1 只支持表中的六种模仿对象，后续新角色复制效果需要单独定义规则与能力映射。

验收包括六种模仿、延后学习、首夜学枪、查验表现与狼队隔离、独立资源、双攻击守护、同守同救、刀权继承、一次性额外刀、过期提交、确定性重放及随机整局。核心用例在 packages/engine/test/mirror.test.ts；随机对局会同时检查私密事件没有进入公开记录。
