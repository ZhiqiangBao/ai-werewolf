## 播放行为核对

失败保留当前发言、已有队列和失败期间新来的事件；重试继续原序列。切换来源使旧回调失效；删除来源阻止继续播放并保留待播内容。手动重听插播成功才去重相同序号，失败或被打断不把自动项记作完成。主动关闭或清空是明确的丢弃操作。

真人行动窗口只由当前席位的真人任务触发，并检查房间运行、未暂停、任务未提交；预告中的 `actionAvailableAt` 用定时器到时让行。没有添加客户端任意延长服务端截止时间的接口。行动窗口里的显式手动重听只覆盖当前手动项，结束或决策变化后恢复让行，界面提示倒计时继续。用户暂停与失败状态不会因取消让行而被当作恢复许可。

房间、凭证、视角与座位变化重建播放控制器。视图加载另外按房间及凭证建立 `ViewLoader` 作用域，旧成功、失败和 SSE 通知不能发布到新作用域。独立核对了 Hook 的状态身份过滤与实际加载器；测试没有真正挂载 React 页面。因此“等效 StrictMode 清理测试”和“实际浏览器严格模式验证”必须区分。

## 合成、HTTP 与关闭行为核对

每个订阅者独立等待和取消；单个 HTTP 连接离开不取消其他订阅者。最后一个等待者退出时，排队任务被移除，已开始任务收到取消请求。取消中的同内容请求快速失败并提示重试；不同未结束任务最多 128 个。等待者总期限覆盖读缓存、排队、提供方与写缓存，共享任务另有不可续期的固定期限。

物理并发上限为 2。取消和超时不会通过 `Promise.race` 提前释放槽；忽略取消的提供方仍占槽至其 Promise 与服务缓存操作真正结束。迟到结果不返回给已取消的订阅者；不会开始后续尚未启动的服务缓存写入。已经启动的文件操作和 Qwen 跨目录缓存复用不能被强制撤回，完整有效缓存可保留。这是已说明的契约边界，不是假称“取消后磁盘绝无写入”。

HTTP 使用请求 `aborted` 和响应提前 `close`，没有把正常读完请求正文误当成取消。对局与试听都接入同一处理；关闭会拒绝新任务、取消等待，并等待实际排空。宽限期内未排空返回状态 2；忽略信号的模块无法由此被强制终止，远端是否停止生成或计费也没有实测证明。

## 模型盲审与处理边界

评分只读取主代理提供的 `discovery-live-blind.json` 和 `holdout-live-blind.json`，只据公开投影、该平民本人的合法信息及实际 `speak` 参数判断。评分阶段未读取映射、原始条件、档位、时延、隐藏底牌或候选系统段；知道研究目的与阶段，因此不称完全盲化。两个评分文件先固定并交付哈希，之后才收到主代理的解盲汇总。

发现阶段评分为 7 pass、2 fail、7 unassessable；留出阶段为 21 pass、2 fail、9 unassessable。逐 ID、引用原句和理由均已核对。独立可达见证以三狼空刀、女巫不用药、全部存活构造同一公开发言下的“双狼对跳”和“真预加狼”两个世界，不能靠上帝底牌推断平民该知道什么。

“必有一真一假”且没有明确假设限定会被双狼见证反驳。“必有一狼”单独出现存在至少或恰好一个的口语歧义，保守记无法判断；“最多一个真预”“至少一人撒谎”可由唯一预言家规则推出。明确保留双狼后“先按一真一假盘”属于带假设的策略，不按事实错误扣分。不得事后要求好人必须诚实、惩罚站边，或解析思考文字替模型补足含义。
