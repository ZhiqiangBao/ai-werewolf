# 媒体动画与单玩家视频验收记录

本页仅记录网页技能动画和单玩家视角视频证据。工程验证按最终 delivery 树记录；不复用先前隔离树的固定测试计数。

## 网页技能动画

五类技能效果为狼刀、查验、毒药、守护和猎枪。主代理实测 23 个浏览器用例：五类动画各覆盖四种视角，共 20 项；另检查凭证、房间和视角切换。

- 五类动画在上帝视角均随事件出现并消失。
- 获授权的 2 号席位按权限显示；9 号席位和观战视角只看见公开的猎枪效果。
- 技能事件到达前序（`seq-1`）无动画。
- 切换凭证、房间或视角后，旧效果队列立即清空为 0。

浏览器 JSON 与五张截图保留在根工作区 `data/media-animation-player/browser-review/`，未复制进 delivery。视频样片 `data/video/skill-effects-demo/skill-effects.mp4` 与主代理已检查的 `preview.png` 也留在根工作区。

## 单玩家视角视频

导出按所选座位过滤历史事件与公开事件，排除终局 `review`。画面只固定显示本人身份，其他席位始终为“身份未知”；授权查验和密谈原话仍按顺序保留，但不反推其他座位身份，也不使用终局 `knownIdentities` 填充历史标签。

CPU 全片矩阵使用三组**合成记录**：普通好人 9 号、狼人 1 号、预言家 5 号。三组都完成全片编码，并对解码后的音轨执行授权音调扫描。它验证合成音轨的授权声源边界，不证明程序能从声音识别角色语义，也不替代真实对局语义测试。

玩家版暂不支持 `--repair-audio` 自动定点重配。需要修复时保留原项目和产物，在新项目目录重新制作。

模型出局后的停收规则与视频历史来源分开：视频读取整局引擎事件，不依赖该席位模型的消息历史。实际核对真实对局 `1877aad04f`：9 号在第 2 天 `dawn`（原始序号 73）出局，玩家导出仍保留其后 7 段公开发言、第 3 天公开流程及 `game.end`；既有剪辑仅省略一条重复法官提示。该完整对局与最新已结束记录的玩家材料准备均已实际执行，未调用真实配音。三种身份的合成验证视频和截图另存于根工作区 `data/media-animation-player/player-examples/`，音轨为诊断提示音。
