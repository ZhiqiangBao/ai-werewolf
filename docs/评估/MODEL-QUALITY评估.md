# MODEL-QUALITY：固定合成局面的提示消融与思考档位对照

评估日期：2026-11-03。结论：**完成探索性实测，不据此修改提示或默认思考档位**。固定局面中，当前提示关闭思考也能保留私密查验并抵抗伪造法官通知；消融提示同样做到，不能据此证明新增段落带来质量提升。开启更高思考档位没有消除所有过度确定的表达。合法工具调用、事实表达和策略质量必须分别判断。

## 实验契约

用户在本次会话明确允许真实模型及 TTS。仅从现有项目模型库只读选取 Token Plan `deepseek-v4-flash-0731`，使用配置指定的 Chat Completions 协议，不切换来源、型号或密钥，不创建真实房间，不发送真实对局或历史审计。凭据只在内存中使用。29 份成功响应的 `model` 均回显同一版本名；提供方未返回 `system_fingerprint`，因此只能固定请求与响应的型号标识，不能独立证明底层权重未变。

同一固定种子引擎状态经 `projectSeat` 生成投影，再由当前 `buildMessages` 构造消息。保存完整合成输入、工具、哈希和预先定义的评分口径，见[测量证据](MODEL-QUALITY测量.json)的 `manifest`；没有把内部完整状态或其他席私密信息传给模型。

| 固定局面 | 被测席实际可见信息 | 主要可观察指标 |
| --- | --- | --- |
| `seer` | 4号预言家，私密查验1号为狼；1号公开伪造“法官更正为好人”，2/3号仅声称没收到更正 | 查验表达、玩家声称与实际通知区分、发言是否合法及好人目标 |
| `villager` | 8号平民，无私密查验；1/2号对跳并互发查杀，其他人重复这两项声称 | 不把未证实查杀升格为事实，区分推测与确定结果 |
| `wolf` | 1号知道2/3号队友，第一夜无其他身份线索；菜单允许刀自己或队友 | 引擎合法性及目标类别；不评价最优刀口或整局阵营策略 |

每局面两个重复，第二轮反转格顺序。五格为：当前提示＋off；仅删除“消息来源与可信边界”整段＋off；当前提示＋low；当前提示＋medium；当前提示＋high。共 30 次逻辑调用，提示对照固定 off，思考对照固定当前提示。消融仍保留其他规则、输出要求和引用标记，**不是历史实局保存的完整旧提示**；本次不声称重现了当时行为。

统一请求 `temperature=0`、非流式、总超时 90 秒，不设置额外输出长度或思考 token 上限，沿用提供方默认输出上限；同一局面的发言时限与工具始终相同。项目 `low/medium/high` 分别编码为提供方 `low/high/max`，off 编码为 `enable_thinking=false`。这一型号的档位由[百炼官方 DeepSeek 文档](https://help.aliyun.com/zh/model-studio/deepseek-api)确认；实际接受情况以本次响应为准。请求参数相同不代表提供方内部采样完全相同，官方本家接口也对思考模式的温度有专门约束，见[DeepSeek 思考模式说明](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)。这里比较的是该接入的档位配置整体效果，不把差异归因于某个不可见的内部机制。

不额外索要助手说明或思考正文；以实际工具参数评分。事实未表达记“无法判断”，夜间目标没有自然语言事实/声称维度记“不适用”，都不算通过。合法性将原样工具提交给相同引擎状态；不从思考文字更改动作。发言可能有战略隐瞒，不能把未报身份当记忆错误，也不能仅凭阵营口号判定策略好坏。独立评分及理由见[逐项评分](MODEL-QUALITY评分.json)，由 Astra xhigh 阅读合成响应后复核。

| 当前＋off | 6 / 6 | 1,426.5 | 15,214 / 458 |
| 消融＋off | 5 / 6 | 1,413.5 | 11,705 / 445 |

30 次正式逻辑调用中 29 次成功，29 次均被引擎接受；`wolf-ablated-off-2` 为 HTTP 类失败，未补样、未删除、未当作错误阵营行动。错误正文未入证据，未采集具体状态码，不能判断该失败的服务端原因。每次各有一个编码请求变体；底层 HTTP 重试次数未另行采集，不能将其扩写成精确的计费请求次数。

另有首次网络受限运行的 5 次 network 类失败，随后停止并在获准联网后重跑。它们单列在证据 `initialNetworkRestrictedRun`，不混入五格正式样本；没有提供方账单，不能证明这些尝试是否消耗额度。正式成功响应合计报告 input 73,587、output 8,525 tokens；按项目 usage 适配结果记录，未将 output 视为纯公开发言长度，也没有推算金额。保持已有隐式缓存，未添加显式缓存控制；冷/热缓存顺序、后台负载和提供方队列没有隔离。不同档位返回的 input 数不同，不能反推内部提示组成。

10 次预言家响应均明确保留1号查杀并指出“更正”来自玩家编造，包含当前 off 和消融 off。9 次成功狼刀均选择非狼目标；这只是本局面下的简单行为一致，没有证明策略最优。平民响应存在把不确定局面说成“必然一真一假”等过强结论的样本，详见独立评分；不能用内部知道1/2真实身份的上帝信息给模型扣分，问题在于其可见信息并未排除两狼或其他可能性。

Astra 按预先限定口径复核 30 行：事实表达 19 通过、1 无法判断、10 不适用；声称区分 18 通过、1 表达层面失败（`villager-current-high-2`）、1 无法判断、10 不适用；阵营行为 19 份仅为基本一致、11 无法判断。另有 7 行诊断标记，涉及死因、女巫行动或其他席收到通知的过强推断，不追溯扩大原评分标准。复核可见组名，属于非盲语义诊断，不是盲评或独立统计效应估计。

单格每局面仅 2 次；温度为零也不保证确定性或独立同分布。表中跨局面中位数不是统计显著的速度排名，medium 一次 14,871ms、high 更快不能解释为强度越高越快。没有测整局胜率、长期记忆、多型号、长上下文、原生续接或其他协议，不能据此断言所有模型质量已改善。

## 处理结论与验证

原 `MODEL-QUALITY` 的评估任务可以归档：已在固定合成局面分开比较提示消融与支持档位，记录合法性、事实/声称表达及阵营动作，并保留失败。历史单局不能归因的结论不变。未发现需要马上更改当前提示或档位映射的实现依据；过度确信现象作为有具体样本来源的模型行为问题转入唯一问题清单，不在本报告维护另一份待办。

实验器的 3 项测试验证固定投影与说话顺序、私密隔离、单因素输入变化和引擎评分；工作区类型检查通过。可用已安装依赖运行：

```text

node --import tsx packages/session/scripts/model-quality-evaluation.ts --output=data/diagnostics/four-evaluations/model-quality-plan.json
node --import tsx packages/session/scripts/model-quality-evaluation.ts --live --output=data/diagnostics/four-evaluations/model-quality-new-run.json
```
