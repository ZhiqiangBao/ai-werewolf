# MODEL-UNSUPPORTED-CERTAINTY：隐藏双生局复现与候选留出验证

日期：2026-11-03。结论：**明确表达现象已在不同公开变体复现，本轮候选不采用，生产提示保持原样；该行为问题继续留在唯一问题清单。** 这是完成了一轮有停止条件的复核和干预评估，不是模型质量问题已解决。

## 预注册和权限

Astra xhigh 在[处理方案](../音频恢复与模型表达处理方案.md)中确定矩阵、评分和停止条件。主代理只复用用户已授权的项目 Token Plan `deepseek-v4-flash-0731`、Chat Completions；只发送固定合成座位材料，不使用真实对局或其他席私密数据，不改模型库或全局配置。48 次逻辑调用全部返回并被同一引擎状态接受，未自动补样。每次一个编码变体，底层 HTTP 重试和账单没有单独采集，不将48次逻辑调用当作已核验的计费请求数。

每个公开变体由引擎构造两个可达世界：1号真预言家且2号狼人；1/2号均狼人且真预言家在其他席。固定8号平民、公开日志、任务、工具和说话顺序，空刀平安夜，不存在女巫死亡链歧义。两份投影、实际消息和工具做完整深等值断言，未删改字段来制造相等；隐藏双生局只作离线证明，不把字节相同的输入再次调用服务冒算独立样本。详见 `model-certainty-evaluation.ts` 和对应测试。

复现阶段采用两种公开措辞、两种真实引擎发言次序，off/high 两档、各两次重复，共16次。项目 high 在该入口编码为 `reasoning_effort=max`；同一具体请求和响应型号固定，但没有底层权重指纹。固定请求温度0、非流式、总超时90秒，沿用服务默认输出上限，没有另外限制思考或正文长度；保持既有隐式缓存。

只有至少两条明确失败且跨至少两个公开变体，才进入预先留出的四个新措辞/次序变体。在留出阶段交错基线/候选、off/high和两次重复，共32次。总上限48次，评分后未追加样本。

候选在新实验响应出现前固定，精确文本见数据的 `manifest.candidate`。它只增加通用的事实、声称和推测边界，明确保留阵营策略中的隐瞒和声称身份；没有写入“对跳可能双狼”或具体测试答案。该段只在实验请求中插入，**未改生产 `buildMessages`**。

## 盲化与裁决

盲包使用随机 sampleId，并打乱顺序；仅包含被测平民真正可见的规则/身份/日志/任务及实际工具输出，剥离系统提示差异、条件标签、档位、隐藏底牌、种子、时延和用量。Astra 先锁定逐条评分与摘要，主代理随后按映射揭盲。评审知道阶段目的；输出风格也可能提示条件，因此不称双盲，也不称对全部实验目的盲化。盲包顺序、文件摘要、冻结评分、完整合成输入、实际行动工具输出及响应元数据均保留在[证据](MODEL-UNSUPPORTED-CERTAINTY数据.json)，原始文件留在忽略的数据目录。

评价对象是公开表达与可见证据的确定性是否相称，不推断内在记忆。站边、倾向、投谁不自动算错；只对明确把尚未确认的身份或查杀当作已确认事实，或排除规则可达反例的确定断言判失败。孤立“必有一狼”“只能有一个”有至少/恰好等歧义时单列无法判断，不能强行记为通过或失败；明确保留双狼可能的假设句按全文判断。

本轮也收紧了上一轮附加诊断：标准九人首夜只有一人出局时，“女巫没救”是否可由规则推出，应核对救毒互斥和死亡链，不能泛称“可能救后仍死亡”作为反例。上一轮原评分原样保留，本轮不把该措辞当作已证实的表达错误；本轮平安夜实验不以它扣分。

## 结果和处理决定

| 阶段/条件 | 逻辑调用及合法交付 | 表达通过 | 明确失败 | 无法判断 |
| --- | ---: | ---: | ---: | ---: |
| 复现，当前提示 | 16 / 16 | 7 | 2 | 7 |
| 留出，同批基线 | 16 / 16 | 8 | 1 | 7 |
| 留出，候选 | 16 / 16 | 13 | 1 | 2 |

复现的两条明确失败来自两个公开变体，均把对跳说成恰好一真一假，满足进入留出的操作门槛。这不依赖上帝知道实际底牌：反例来自本席不可区分、规则可达的双狼世界。

留出基线与候选的主要指标均为 **1/16 条明确失败**，候选未降低主要指标；合法交付均16/16。候选虽有更多可判定通过、更少歧义，但不能改用次要指标宣布主问题改善。依照预注册采用门槛，**不采用候选，不改默认思考档或生产提示**。基线失败在high(max)，候选失败在off，不能由单个样本归因于思考强度，也不能宣称任何档位已消除该现象。

本轮只覆盖一型号、一个接入、八个公开变体和两个档位，各重复两次；没有测整局胜率、长局记忆、多协议、所有语言和长期统计效应。48次上限已用完且停止，没有为获得理想结论追加试验。小样本中“1对1”也不证明两条件总体相同，未计算统计显著性。

`MODEL-UNSUPPORTED-CERTAINTY` 保留原稳定编号，更新为“已复现；本轮候选未达到采用门槛”。进一步干预需要先提出新的可检验假设和独立留出验收，不复用本轮已揭盲材料作为新候选的验证集，不追认本轮实验已完成生产修复。具体活动状态与验收只在[待解决问题](../待解决问题.md)维护。

## 验证与复现入口

实验器两项本地测试检查隐藏双生局的完整相等、发言次序、席位私密隔离、留出措辞和候选的单因素差异；工作区类型检查通过。无 `--live` 仅生成清单；输出已存在时拒绝覆盖。真实运行需沿用用户已授权服务，不能自动跨越复现门槛运行留出。

```text
node node_modules/vitest/vitest.mjs run packages/session/test/model-certainty-evaluation.test.ts
node --import tsx packages/session/scripts/model-certainty-evaluation.ts --output=data/diagnostics/certainty/new-plan.json
```

实际命令为上述脚本增加 `--live`（16次复现）；仅在独立评分确认门槛后增加 `--holdout`（32次配对留出），各用新的输出路径。复现这些真实调用将再次消耗服务额度；本报告本身不触发任何调用。源码和证据 SHA-256 记录测量工作区原始字节，跨克隆应留意 Git 换行转换。
