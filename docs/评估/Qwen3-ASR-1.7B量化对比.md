# Qwen3-ASR 1.7B Q5 与 Q8 实测

日期：2026-11-03。结论仅覆盖本机这30段真实对局原话的Qwen TTS音频；它们不是麦克风真人录音，也不是人工转写金标准。

Q8在本组日语上明显减少文本差异，中文仅一段小幅改善、英语持平；按用户最终选择，按需使用ASR时中文/英语改用Q8，日语继续在线Qwen；Q5权重在Q8服务验证后删除，保留测试记录。日常制片默认不额外运行ASR，本轮不部署本地TTS。

## 固定材料与比较条件

- 中文、英语、日语各10个不同的公开发言事件，总30段、861.20975秒。各语种取对应已结束局前10个公开发言的第一个未改写制作片段，保留节选标记和完整原稿摘要；每语种来自一局。中10段及英日各1段复用已有音频，其余18份用已授权的在线Qwen TTS补配。英日主要固定各一条声线，泛化范围有限。
- 原文、选样规则和空别名策略先固定；一段英语初次音频末尾出现约0.62秒满幅平直，按既有波形门禁同文同声线递增seed一次修复，在任何识别前选定首个波形合格版本，失败版本保留。之后没有按识别结果重配或挑样。
- 三种ASR接收同一份16kHz/单声道/PCM16 WAV字节，自动识别语言，不提供原稿、热词、前段上下文。原稿只在独立结果落盘后评分。30份在线Qwen响应各请求一次，无计费线路切换。
- 两份GGUF为同仓库、同revision，张量名和形状完全相同。除general.file_type外元数据一致；709个张量中，Q5为365 F32、52 Q8_0、291 Q5_K、1 Q6_K；Q8为365 F32、344 Q8_0。不能称整文件纯INT5/INT8。
- 同一transcribe.cpp/binding/native 0.4.1、native commit 4d7c1cc，Vulkan1 RTX5060 Laptop 8GB。按Q5-r1、Q8-r1、Q8-r2、Q5-r2、Q5-r3、Q8-r3交替，每轮独立进程，只驻留一份模型；先公共非计分音频预热，再以固定乱序处理30段，各用新session、不使用转写缓存。共180次正式本地识别，三轮每段转写完全一致。

## 关键差异与采用范围

A/B文本复核发现，Q8修正了若干日语词义错误，如人影/陣営、審議/真偽、視界/司会；它仍会发生占卜动作/否定、角色名、脱落/登録等关键差异。中文主要收益集中一段；另有8、12在本地或云端变成无分隔数值的歧义。云端同样有votes/volts、毒/读等错词。数字、否定、人物/角色和漏增句需要单独核对，不能只看总分。该复核基于独立转写文本，不冒称人工音频听审，冻结分数不为同音字临时加别名。

两套另测了静音和旧日语instruction污染音频：静音均空文本，污染语音均返回包含额外内容的转写；这些负例单独保存，不计入30段质量或性能汇总。truncated=null表示运行时未提供明确截断结论，不等同于已证明没有截断。

本组证据支持“Q8在这些日语样本减少差异，代价是更慢和更多显存”；不支持普遍精度保证。中文只在1/10段改善、英语全平；用户明确接受显存与速度成本，最终选择中英Q8并删除Q5。日语生产仍只在线Qwen，ASR默认按需而非每段必跑。
