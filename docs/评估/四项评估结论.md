## 证据与验收

主代理完成集成检查：13 个相关测试文件共 **55 项通过，0 失败**，工作区 TypeScript 检查通过。覆盖 factory、现有真人 HTTP/SSE、邀请网络、进程关闭、语音并发/缓存/客户端中止、真人投影权限、事件原型故障恢复和模型实验器。紧凑结果及源码摘要见[验证摘要](验证摘要.json)；原始 Vitest 输出位于忽略的 `data/diagnostics/four-evaluations/integration-tests.json`。没有重跑全仓库所有业务测试，未改网页源码，未开展真实设备或扬声器测试。

使用 Node v24.18.1、Windows x64 和已安装的本地 Vitest/TypeScript。默认 `pnpm` 入口遇到 PowerShell 模块及 Corepack 网络限制，已改用等效本地入口；HTTP 测试在获准连接本机临时端口的环境运行。真实模型和 TTS 使用用户本轮明确授权的现有项目服务，不写回模型库或全局配置，不操作已有对局。

按用户指定分工：Astra xhigh 设计验收边界并独立复审；Terra xhigh 执行存储、HTTP 和音频小测试；Luna xhigh 做只读资料盘点；主代理集成、运行模型对照并验收。审查发现的事件原型补丁引用泄漏已修复，并重新测量、更新源码哈希；详情见[独立审查](四项评估审查.md)。该审查为同一 Codex 工作流程中的独立模型复核，不冒称第三方机构审计。

归档保留测量环境、源码摘要、合成输入、参数、返回工具及评分；不提交密钥、真实房间、思考/原生块、媒体文件或私密对话。仅本轮新增文件及 HTTP 提取进入提交，既有 `.gitignore` 改动保留给原任务。
