# 固定规则与信息分发

更新：2026-11-01。本次只修订固定系统提示、规则卡与工具说明，不改变裁决、事件受众、竞选版本、消息追加方式或模型协议。

## 修改原则

项目负责把实际规则和信息接口说明准确；玩家自行记忆发言、判断真假、形成局势认识并作出决策。模型忘记、串号或附和不作为逐轮补充事实、重述身份、修正历史或增加策略提示的理由。

原有消息前缀、后缀与当前许可菜单保持原样。每席系统提示在上下文首次建立时写入，既有 system 和原生续接历史不回写；隐式缓存策略不变，不新增显式缓存写入。完整新模板用于新房间，旧对局事实不重新裁定。

## 已澄清的固定条款

| 范围 | 当前说明 |
| --- | --- |
| 身份、阵营、职务 | 阵营决定胜负，角色身份决定技能；好人包含平民与神职。警徽只移交警长职务，不移交技能或私密记录。 |
| 夜间行动 | 各阶段完成后统一结算攻击和保护；行动被接受不保证攻击或保护效果成立。工具描述使用「选择目标」「使用药品」，避免提前宣布结算。 |
| 普通狼人 | 密谈、合刀结果及并列时的各狼选择仅向当夜参与行动的存活普通狼人发送。「狼人阵营成员」用于胜负，「普通狼人」用于密谈、互认、合刀和自爆。 |
| 守卫 | 仅本人收到守护选择回执，不获知刀口或是否挡住攻击，不向目标另发守护通知。 |
| 女巫 | 刀口与用药回执只向本人反馈，不向被救者或被毒者另发通知；解药用完后不再获知刀口。 |
| 查验 | 只向查验者私密反馈，不通知被查验者；进行中的对局不会因查验者死亡或移交警徽而自动公开、转交记录。阵营查验不返回具体身份。 |
| 猎人 | 符合条件时私下询问本人，实际开枪公开猎人表现与目标；放弃是否亮身份按开局配置。 |
| 觉醒隐狼 | 模仿改变具体身份查验表现，不改变真实身份或阵营；学习当夜结束获得技能，夜间主动技能从下一夜起可用。 |
| 送达范围 | 思考、普通助手正文和旁听回应不发给其他玩家；只有被接受的发言调用按其频道送达，被拒绝的提交未执行。 |
| 自爆与胜负 | 自爆结算产生的遗言不开放再次自爆。先完成同批次出局技能及死亡连锁，再判定胜负；双方条件同时满足时好人优先。 |

同时限定「发言方向由法官随机」仅适用于无警长的情形，并将旧版工具中内部整数权重 2／3 的显示修正为玩家实际看到的 1／1.5 票。动作名称、参数、资源和结算均未改。

## 审阅与生成

固定规则的来源仍是角色模块、规则卡生成器与协议工具目录；本文件说明本次调整范围，不另建一套规则来源。[系统提示词审阅稿](系统提示词审阅稿.md)从源码展开标准十二人和镜隐迷踪的规则卡、身份说明与工具描述：

```sh
pnpm exec tsx packages/llm/scripts/export-prompt-review.ts
```

生成仅使用独立合成场景，不读取真实房间、密钥、模型配置或视频素材，不调用外部模型或 TTS。原始对局与审计留在忽略的数据目录。

## 验证范围

本次规则、提示词、工具、视角和上下文相关回归共 18 个文件、198 项通过，TypeScript 检查通过。协议回归仅使用本机模拟接口，不推进真实对局，也不运行视频制作任务。没有新增真实模型对局或问答，因此不据此声称模型幻觉已经减少。

发言后退水仍是独立功能任务，本次没有引入新的竞选阶段，也没有把该功能写成已经可用。
