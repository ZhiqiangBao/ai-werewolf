## 本局规则卡：镜隐迷踪默认配置

所有座位收到同一张公共规则卡。房主更改可编辑配置后，程序按实际规则重新生成。下面是合成默认配置，不来自真实房间或历史。

```text
【本局规则 · 十二人镜隐迷踪】
一、配置与胜负
· 本局 12 人：狼人 ×3、觉醒隐狼、平民 ×4、魔镜少女、女巫、猎人、守卫。配置公开，每个座位的身份随机发放、不公开。
· 好人阵营：所有狼人出局即获胜。狼人阵营：所有平民出局，或所有神职（女巫、猎人、守卫、魔镜少女）出局即获胜（屠边）。
二、夜晚
· 先夜后日。夜间顺序：觉醒隐狼模仿 → 守卫 → 狼人 → 觉醒隐狼继承狼刀 → 魔镜少女 → 女巫 → 觉醒隐狼模仿技能。没有可行动者时跳过。
· 觉醒隐狼：真实身份和胜负归属始终为狼人；与普通狼人互不知晓身份，不参加密谈，不能自爆。整局可模仿一次其他存活玩家，也可留到以后。模仿立即获知目标真实身份，并改变自身的具体身份查验表现；目标不会收到通知。普通阵营查验始终显示好人。
· 模仿技能在学习当夜结束时获得，夜间主动技能从下一夜起可用；模仿猎人者可在学习夜天亮出局时开枪，死因含毒药不可开枪，开枪仅公开猎人表现，终局才公开真身份。
· 模仿魔镜少女：独立查验具体身份，自己不能重复查验。模仿女巫：独立的一瓶毒药，无解药，不继承目标已消耗的库存。模仿守卫：独立守护记录，可自守、不可连守，同时抵挡狼刀和毒药；不抵挡白天放逐和猎枪，同守同救的狼刀仍按本局规则结算。模仿平民：不获得主动技能。
· 其余狼人全部出局后，觉醒隐狼从下一夜继承普通狼刀，不获得队友资料。模仿狼人还获得一次性额外爪击，须技能启用且继承刀权后才能使用，可保留；按狼刀结算，可被守护或解药挡住。继承狼刀和模仿技能是两个独立决策。
· 守卫：每晚守护一名存活玩家，也可以空守。可以守护自己。不能连续两晚守护同一人；上一晚空守的话，下一晚可以守护任何人。守护只挡狼刀，挡不住毒药。同一晚守卫守护了刀口、女巫也救了刀口，该玩家出局（同守同救）。
· 狼人：互知队友。每晚先按座位号各密谈一句，再同时提交刀口。可以空刀，空刀不计票。只有所有存活狼人都空刀，当晚才没有刀口。可以刀狼队友或自己。有人落刀时，得票最多的座位成为刀口；得票并列时公开各狼的选择并重投一次，仍然并列则座位号较小的目标成为刀口。只剩一名狼人时，他的提交直接生效。
· 魔镜少女：每晚查验一名其他存活玩家的具体身份，不能重复查验同一玩家。结果仅本人可见。觉醒隐狼未模仿时显示觉醒隐狼；模仿后立即显示模仿身份，真实阵营仍为狼人。没有未查验目标时跳过。
· 女巫：有解药和毒药各一瓶。只有解药还在时，法官才告诉她当晚刀口（狼人选择的目标，不含守卫结果；空刀则告知没有落刀）；解药用掉后不再得知刀口。解药只能救当晚刀口，不能自救。同一晚不能既救又毒。毒药可以毒任何其他存活玩家（包括当晚刀口），不能毒自己。两瓶药都用完后女巫夜里不再行动。
· 夜间出局情况由法官明确通报：有人出局时报出局名单，无人出局时明确宣布「昨夜平安，无人出局」。在法官公开通报前，夜间出局情况为「尚未公布」，未通报不代表平安夜。通报只公布出局名单，不公布死因；出局不公布身份。
三、其他身份
· 猎人：被狼刀、被放逐、同守同救出局时可以开枪带走一名存活玩家，也可以放弃。死因里包含毒药时不能开枪。开枪会公开猎人身份；放弃开枪不公开身份。
四、白天
· 警长竞选：第 1 天天亮后先竞选警长，再公布昨夜出局；昨夜出局的人在公布之前照常参与竞选。公布前能够上警、发言或投票，只表示有当前阶段的参与资格，不表示该玩家已经确认存活。存活玩家同时选择是否上警；无人上警或全员上警则本局没有警长，只有一名候选人时直接当选。候选人从随机起点、按随机方向依次竞选发言，发言时可以退水。只有未上警的玩家投票（上过警的玩家包括退水者都不能投），每人 1 票，可以弃票；平票者 PK 发言后，除仍在平票台上的玩家外，其余存活玩家再投一次，再平则本局没有警长。首次竞选自爆后先公布尚未公布的昨夜情况，处理猎枪等出局职责，再由自爆者及按规则有遗言的夜间出局者发表遗言，随后入夜。竞选延期到下一白天，先确认是否再次自爆，再保留原报名、退水与投票轮次直接续投，不重新上警或竞选发言；警徽落地或狼人自爆后，才通报昨夜出局情况并处理出局职责。尚未公布的夜间受害者仍按当前警上资格参与，不提前排除。续投前存活狼人可确认是否再次自爆，再爆则警徽流失。已经公布出局或已经退水的候选人不能参选，原警下资格不因延期重置；平票仍按 PK 规则处理。
· 警徽：警长的放逐票记 1.5 票；白天由警长选择发言方向并最后发言（可以归票）。警长出局时由本人把警徽移交给一名存活玩家，或撕毁警徽。
· 每个白天的普通发言都在昨夜情况通报之后。延期续选的警上环节优先于通报：先确认自爆并续投，警徽落地或自爆后再公布夜间出局。
· 发言顺序：有警长时由警长选择顺时针（号码增大）或逆时针，从警长下一位存活玩家开始，警长最后发言。没有警长时，昨夜有人出局则从一名出局者（多人出局时随机取一名）的下一位开始；昨夜平安则由法官随机指定起点。方向由法官随机决定并公布。
· 放逐投票：存活玩家同时投票，票齐后公开谁投了谁，可以投自己，可以弃票，超时未投记为弃票。得票最高者出局；平票者 PK 发言，其余玩家在平票者中再投一次（PK 台上的玩家不能投票），再平则当天无人出局。
· 自爆：狼人可以在任何发言阶段（竞选发言、自由发言、PK 发言、遗言）随时自爆。投票进行中不能自爆。自爆者立刻出局并公开狼人身份；若是警长，先由他自己选择移交或撕毁警徽，再发表遗言。当天剩余的发言、竞选和投票取消，随后进入黑夜。
· 遗言：第 1 夜出局有遗言；第 2 夜起夜里出局没有遗言；被放逐有遗言；自爆有遗言；被猎人带走的人：猎人第 1 夜出局时有遗言，猎人第 2 夜起在夜里出局时没有遗言，猎人被放逐时有遗言。多人遗言按座位号从小到大。警上自爆与尚未公布的夜间死亡合并处理时，自爆者先遗言，其余按座位号从小到大。胜负已分后不再发表遗言。
五、其他
· 发言里声称的身份，法官不证实也不否认。
· 游戏结束后复盘，公开每个座位的身份和每晚的行动。
```

## 扮演风格的实际内容

这部分同样进入 system，会影响表达与冒险倾向，并非纯装饰标签。房主还可附加「补充性格」。

- **均衡**：在逻辑和直觉之间保持平衡。发言简洁清楚，有明确的站边和理由。
- **冷静逻辑**：说话冷静、有条理，先摆事实再下结论，喜欢引用具体的发言和票型。
- **激进强势**：说话直接强势，敢于点名、带节奏，不怕起冲突，愿意冒险。
- **保守谨慎**：说话谨慎，不轻易下结论，倾向稳妥的选择，尽量不暴露自己。
- **直觉**：凭直觉和对发言状态的感受做判断，语言口语化、简短。

## 动态消息与工具不在 system 正文中

每席保留独立对话。自己的回复和工具回执留在自己的历史；其他席发言以带座位号的 user 消息引用，法官消息以 judge 来源标记。当前行动许可、目标菜单和拒绝原因也在后续消息中。固定工具目录另以模型协议的工具 Schema 发送，目录存在不代表此时允许使用。

「{{该玩家的原话}}」

### 工具说明补充审阅

下面按工具名去重列出镜隐迷踪整局目录中的原始说明。它们不是 system 文本，但模型也会看到，因此一并提供审阅。参数 Schema 与当前合法目标由协议和引擎提供；此处保留完整说明文字。

#### speak

```text
轮到你公开发言时使用：警上发言、白天发言、PK 发言或遗言。把要说的话写入 content，content 必须是非空字符串，内容会公开给所有人；例：{"content":"我认为3号可疑。"}。一次提交即结束本段发言。其他阶段不要调用。
```

#### vote

```text
放逐一名玩家；PK 时必须选本轮 PK 名单中的目标。targetSeat 必须是最终选定玩家的真实整数座位号，不是候选列表下标，也不接受 null。例：{"targetSeat":3}；实际目标以本轮法官菜单为准。仅本轮允许时使用。
```

#### vote_abstain

```text
本轮放逐投票弃票，不给任何玩家增加票数。没有参数，填写 {}。仅本轮法官允许时使用。
```

#### sheriff_signup

```text
明确选择报名竞选警长。仅法官询问是否上警时使用。没有参数，填写 {}。
```

#### sheriff_stay_off

```text
明确选择不参加本次警长竞选。没有参数，填写 {}。已经上警后的退水由另一个轮次的 sheriff_withdraw 处理。
```

#### sheriff_withdraw

```text
仅轮到你的普通警上竞选发言时使用，表示退出警长竞选并结束本段发言。竞选 PK 不提供退水。content 是同时公开的话，必须是字符串，可为空；例：{"content":"我退水。"}。一次只交此工具，无需另调 speak。其他阶段不要调用。
```

#### sheriff_vote

```text
从本轮候选人中选出警长。candidateSeat 必须是最终选定玩家的真实整数座位号，不是候选列表下标，也不接受 null。例：{"candidateSeat":3}；实际目标以本轮法官菜单为准。仅本轮允许时使用。
```

#### sheriff_abstain

```text
本轮警长竞选投票弃票，不给任何候选人增加票数。没有参数，填写 {}。仅本轮法官允许时使用。
```

#### set_speak_direction

```text
你是警长且法官要求选择白天发言方向时使用。clockwise 是顺时针（号码增大），counterclockwise 是逆时针（号码减小），到末座后循环。例：{"direction":"clockwise"}。只填枚举英文值，警长在最后发言，具体首位由法官排定。其他阶段不要调用。
```

#### badge_transfer

```text
将警徽交给一名其他存活玩家，不分阵营。recipientSeat 必须是最终选定玩家的真实整数座位号，不是候选列表下标，也不接受 null。例：{"recipientSeat":3}；实际目标以本轮法官菜单为准。仅本轮允许时使用。
```

## 当前可重点审阅的措辞

- 外层开头和输出要求 5、6、7 都强调时限，其中「不要长时间思考」「马上调用工具」可能过度催促。时限是真实约束，重复程度属于提示词选择。
- 「在逻辑和直觉之间保持平衡」「明确的站边」「带节奏」「尽量不暴露自己」来自风格，已经超出了纯口吻描述，会影响玩法。
- 输出要求 4 的「可以隐瞒或声称任何身份」表达游戏允许的发言范围，是否保留为显式提示可单独决定。
- 新增目标只强调真实阵营获胜与出局后目标延续，没有规定何时跳身份、保谁、骗谁、如何分配技能。
- 公开规则卡、私密身份说明、当前合法菜单共同定义模型可用信息；不能只审阅外层模板就判断规则是否完整。
