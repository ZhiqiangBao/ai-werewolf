### SERVICE-DEV-SHUTDOWN：核对开发服务正常收尾返回超时

- **优先级：** P2
- **状态：** 两次真实环境观察，原因待确认；服务已恢复
- **事实依据：** 2026-11-03 更新本席结束信号时，确认无进行中房间后执行正常重启，控制接口返回收尾失败或超时并停止启动替代服务。随后核对旧服务已退出、租约释放，按原开发模式重新启动成功；49 个历史房间文件哈希完全不变。不能据此断定是房间保存失败或特定连接造成，也不能将恢复服务写成根因修复。
- **补充观察：** 2026-11-11 加载思考强度修复时再次出现相同收尾超时；日志记录仍有连接或资源未完成收尾。管理命令未启动替代进程，随后 `status` 确认服务未运行，再使用保存的 dev 设置启动并通过健康检查。本次未确认具体资源原因，也未重复执行 2026-11-03 的历史文件哈希对比。
- **验收标准：** 在隔离数据与开发前端环境复现，区分 HTTP/SSE、升级连接、前端关闭和其他资源的收尾阶段；修正后正常停止返回成功、所有本项目资源退出、保存文件完整且重启可用。真实复查范围和未复现的分支需明确记录。

### ACCESS-REMOTE：明确远程管理认证、凭证轮换与席位转交

- **优先级：** P2
- **状态：** 需求与威胁边界待确认
- **事实依据与边界：** 当前凭证链接持有人可代表该席行动；尚无独立账号、抢座或席位转让功能。远程部署额外需要管理认证和凭证撤销／轮换策略。本项不把单机／局域网邀请当作多租户账号系统。

### MODEL-UNSUPPORTED-CERTAINTY：复核模型把未证实局面说成确定事实的表达

- **优先级：** P2
- **状态：** 已复现；本轮候选未降低主指标，未采用，核心现象仍待解决
- **来源：** 2026-11-03 [本轮复核报告](评估/MODEL-UNSUPPORTED-CERTAINTY评估.md)、[合成输入、输出与冻结盲评分](评估/MODEL-UNSUPPORTED-CERTAINTY数据.json)及[Astra 独立审查](音频恢复与取消独立审查.md)。历史来源为[首次评估](评估/MODEL-QUALITY评估.md)中的 `villager-current-high-2`；本轮明确复现行 `5a4ebc33-a40d-482a-bb3f-6fc9968565b2`、`28797ad9-149d-47bd-91a6-6ce05e2356ab`，留出基线与候选仍各有一行明确失败。
- **事实依据与边界：** 引擎生成真预加狼、双狼两个隐藏世界，本席完整投影、消息和工具相同。16次复现有2条明确过强表达，跨2个公开变体；32次配对留出中基线和候选均为1/16明确失败，合法交付均16/16。48次逻辑调用全部保留，无补样；候选没有达到预定义主指标改善门槛，因此没有修改生产提示或默认档位。更多可判定通过不能替代主指标。现象是表达超出可见证据，不直接证明内在记忆、协议或源码缺陷，也不因上帝底牌惩罚站边策略。
- **诊断口径修正：** 旧评分里“女巫没救”的附加怀疑需按本版型救毒互斥和死亡链核对，不再当作已证实错误；本轮用平安夜双生局，未以该措辞扣分。历史评分保留，具体更正见本轮报告。
- **验收标准：** 后续先提出新的可检验干预与有限矩阵，再使用未揭盲、未用于设计候选的独立留出变体；固定投影、型号和协议，分开比较提示与支持档位。预定义事实/玩家声称/推测/无法判断的保守口径，每个否定必然性的判定须有规则可达、同可见信息的反例；保留失败和歧义，先冻结盲评分再揭盲。达到预设主指标且合法行动/角色边界不退化才有采用依据，不要求泄露私密信息或替狼人强制诚实，不以新增提示文字本身作为改善证据。

## 真人与跨设备体验

### VOICE-ASR：提供可选择的语音输入入口

- **优先级：** P2
- **状态：** 方案待确认，未实施
- **事实依据与边界：** 当前只提供系统／输入法听写说明，没有项目录音按钮或 ASR 服务。浏览器系统听写唤起能力不统一；可能方案包括系统指引、在线 ASR 或本地服务。
- **验收标准：** 明确平台能力、语言、音频格式、密钥存放、失败和取消语义；识别结果写入当前席位草稿，经玩家检查和手动确认后再提交 `speak`，不代写或修改观点。

### MOBILE-CROSS-DEVICE：完成手机与第二台设备验收

- **优先级：** P2
- **状态：** 待真实设备验证
- **事实依据与边界：** 已在桌面浏览器和同一电脑的局域网地址上验证部分页面；尚未真实手机扫码，也未由第二台设备验收。不能把窄视口检查等同于 iOS／Android 或跨设备适配。
- **验收标准：** 分别记录 iOS、Android 原生输入／朗读可用性，并用手机和另一台局域网设备检查扫码、候场、发言、跨应用返回和断线重连；按实际验证设备和系统列出结论。该验收只证明被测设备上的页面与会话体验，不证明草稿在设备间同步。

### DRAFT-CROSS-DEVICE：确认真人草稿是否需要跨设备同步

- **优先级：** P2
- **状态：** 建议待确认
- **事实依据与边界：** 真人发言草稿当前保存在浏览器标签页的会话存储中，可在同一页面刷新恢复；跨设备草稿同步尚未实现。手机页面／重连验收不能替代同步能力验证。
- **验收标准：** 先确认是否需要在同席的不同设备间同步草稿及冲突规则；若实施，验证席位与决策隔离、重连和并发编辑，不能让旧决策草稿提交到新行动窗口。

### INVITE-SHORTLINK：评估站内邀请短链

- **优先级：** P3
