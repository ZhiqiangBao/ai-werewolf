### DEEPSEEK-THINKING-CAPABILITY：补齐官方模型名称与原生协议思考档位识别

- **优先级：** P2
- **状态：** 已定位能力识别遗漏，待实现与验证；本轮只读诊断，未修改模型配置或调用真实模型。
- **事实依据：** 2026-11-04，`packages/protocol/src/thinking.ts` 的 Chat Completions 分支仅匹配 `deepseek-v4` 前缀，漏掉官方 `deepseek-flash`，界面因此禁用其轻度／标准／深度。官方入口的 Responses、Anthropic 分支也未识别 DeepSeek。旧 `deepseek-v4-*` 在 Chat Completions 下按当前实现应可选强度，尚未据此复现用户所见的全部界面状态。核对 [官方思考参数](https://api-docs.deepseek.com/guides/thinking_mode/) 与[版本记录](https://api-docs.deepseek.com/updates/)，`deepseek-flash` 当前指向 V4.1 Flash，支持 low／high／max；不能把官方能力无条件套用到同名第三方入口。
- **验收标准：** 按精确官方入口、型号与协议分别确认选项和实际请求参数，覆盖当前名称、旧别名、关闭、三档映射、未知型号及第三方入口；验证网页模型切换和服务端校验一致，保留现有百炼特例与旧存档兼容。尚未实施时不能宣称模型不支持或已修复。

### MODEL-UNSUPPORTED-CERTAINTY：复核模型把未证实局面说成确定事实的表达

- **优先级：** P2
- **状态：** 已复现；本轮候选未降低主指标，未采用，核心现象仍待解决
- **来源：** 2026-11-03 [本轮复核报告](评估/MODEL-UNSUPPORTED-CERTAINTY评估.md)、[合成输入、输出与冻结盲评分](评估/MODEL-UNSUPPORTED-CERTAINTY数据.json)及[Astra 独立审查](音频恢复与取消独立审查.md)。历史来源为[首次评估](评估/MODEL-QUALITY评估.md)中的 `villager-current-high-2`；本轮明确复现行 `5a4ebc33-a40d-482a-bb3f-6fc9968565b2`、`28797ad9-149d-47bd-91a6-6ce05e2356ab`，留出基线与候选仍各有一行明确失败。
- **事实依据与边界：** 引擎生成真预加狼、双狼两个隐藏世界，本席完整投影、消息和工具相同。16次复现有2条明确过强表达，跨2个公开变体；32次配对留出中基线和候选均为1/16明确失败，合法交付均16/16。48次逻辑调用全部保留，无补样；候选没有达到预定义主指标改善门槛，因此没有修改生产提示或默认档位。更多可判定通过不能替代主指标。现象是表达超出可见证据，不直接证明内在记忆、协议或源码缺陷，也不因上帝底牌惩罚站边策略。
- **诊断口径修正：** 旧评分里“女巫没救”的附加怀疑需按本版型救毒互斥和死亡链核对，不再当作已证实错误；本轮用平安夜双生局，未以该措辞扣分。历史评分保留，具体更正见本轮报告。
- **验收标准：** 后续先提出新的可检验干预与有限矩阵，再使用未揭盲、未用于设计候选的独立留出变体；固定投影、型号和协议，分开比较提示与支持档位。预定义事实/玩家声称/推测/无法判断的保守口径，每个否定必然性的判定须有规则可达、同可见信息的反例；保留失败和歧义，先冻结盲评分再揭盲。达到预设主指标且合法行动/角色边界不退化才有采用依据，不要求泄露私密信息或替狼人强制诚实，不以新增提示文字本身作为改善证据。
