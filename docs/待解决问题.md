## 架构、运行与验证

### ARCH-EVENT-STORE：测量事件追加与快照存储的可行性

- **优先级：** P2
- **状态：** 建议先测量，尚未决定迁移
- **事实依据与边界：** 当前状态保存会克隆和序列化整局数据，历史评估提出长局、多房间和观看者可能放大成本；尚无相应负载基线。此条要求评估事件追加与定期快照的可行性，不预设全面替换现有文件存储。
- **验收标准：** 对代表性长局测量写入、签名、恢复耗时和存储量；原型在崩溃恢复时无行动丢失或重复，并保留现有导出格式。基于数据再决定是否实施。

### ARCH-HTTP-FACTORY：评估 HTTP server factory

- **优先级：** P2
- **状态：** 建议待排期
- **事实依据与边界：** 当前服务入口在 `main.ts` 顶层创建存储与管理器；独立启动进程使部分 HTTP 场景难以隔离测试。本项是测试和生命周期边界建议，不要求改变路由语义。
- **验收标准：** 可注入存储与管理器创建服务器实例；请求体边界、错误响应、SSE 关闭和连接清理可隔离测试，现有 HTTP 行为不变。

### ACCESS-REMOTE：明确远程管理认证、凭证轮换与席位转交

- **优先级：** P2
- **状态：** 需求与威胁边界待确认
- **事实依据与边界：** 当前凭证链接持有人可代表该席行动；尚无独立账号、抢座或席位转让功能。远程部署额外需要管理认证和凭证撤销／轮换策略。本项不把单机／局域网邀请当作多租户账号系统。
- **验收标准：** 先确认管理面、玩家面与观战面的权限需求，再定义凭证轮换和席位交接规则；管理、座位、观战的 HTTP 权限、撤销、过期和旧存档兼容均有测试。

### AUDIO-LIFECYCLE：测量首音频延迟并明确取消语义与每席音色

- **优先级：** P2
- **状态：** 建议待评估
- **事实依据与边界：** 已有浏览器／服务端播放接口、提供方接入、并发限制和取消客户端等待逻辑；停止页面播放不保证服务端合成或计费被撤销。尚需测量首音频延迟，明确不同提供方的取消边界，并决定是否支持逐席音色。不能将已有音频功能说成未实现。
- **验收标准：** 记录生成首段和完整音频耗时；文档区分页面停止、HTTP 取消与提供方计费；音色来源在席位配置及投影权限内可核对，失败不丢失待播内容或挤占决策时间。

### MODEL-QUALITY：在同局面下区分提示词与思考强度影响

- **优先级：** P2
- **状态：** 建议待设计
- **事实依据与边界：** 历史实局使用 `thinkingMode=off`，且当时保存的系统提示不含当前源码已有的消息来源边界段，不能作为当前提示的能力对照。模型质量问题不能单凭一局归因于提示词或思考配置，也不调用未经授权的真实服务。
- **验收标准：** 固定合成局面、座位可见信息和模型版本，分开比较提示词版本与该型号支持的思考档位；记录事实记忆、声称区分、行动合法性及阵营行为，不混淆两个变量，也不将提示本身当作质量提升证据。

## 真人与跨设备体验

### VOICE-ASR：提供可选择的语音输入入口

- **优先级：** P2
- **状态：** 方案待确认，未实施
- **事实依据与边界：** 当前只提供系统／输入法听写说明，没有项目录音按钮或 ASR 服务。浏览器系统听写唤起能力不统一；可能方案包括系统指引、在线 ASR 或本地服务。
- **验收标准：** 明确平台能力、语言、音频格式、密钥存放、失败和取消语义；识别结果写入当前席位草稿，经玩家检查和手动确认后再提交 `speak`，不代写或修改观点。

### MOBILE-CROSS-DEVICE：完成手机与第二台设备验收

- **优先级：** P2
- **状态：** 待真实设备验证
- **事实依据与边界：** 已在桌面浏览器和同一电脑的局域网地址上验证部分页面；尚未真实手机扫码，也未由第二台设备验收。不能把窄视口检查等同于 iOS／Android 或跨设备适配。
- **验收标准：** 分别记录 iOS、Android 原生输入／朗读可用性，并用手机和另一台局域网设备检查扫码、候场、发言、跨应用返回和断线重连；按实际验证设备和系统列出结论。该验收只证明被测设备上的页面与会话体验，不证明草稿在设备间同步。

### DRAFT-CROSS-DEVICE：确认真人草稿是否需要跨设备同步

- **优先级：** P2
- **状态：** 建议待确认
- **事实依据与边界：** 真人发言草稿当前保存在浏览器标签页的会话存储中，可在同一页面刷新恢复；跨设备草稿同步尚未实现。手机页面／重连验收不能替代同步能力验证。
- **验收标准：** 先确认是否需要在同席的不同设备间同步草稿及冲突规则；若实施，验证席位与决策隔离、重连和并发编辑，不能让旧决策草稿提交到新行动窗口。

### INVITE-SHORTLINK：评估站内邀请短链

- **优先级：** P3
- **状态：** 建议待确认
- **事实依据与边界：** 当前可生成本地座位／观战二维码和完整邀请链接，按权限区分；尚无站内短链。本项仅在完整链接仍不便分享时考虑，不依赖第三方平台转存凭证。
- **验收标准：** 如决定实施，短链使用不可猜测凭证映射，支持到期与撤销，保持房主、座位和观战权限隔离，并兼容已有完整邀请和存档。
