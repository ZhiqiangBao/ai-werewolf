# 十二人奇迹商人规则

房主在建房页选择「十二人奇迹商人」（`merchant12`），可安排真人、模拟玩家和已配置的模型同桌。下文说明版型的默认规则。房主调整选项后，所有座位按房间内的规则卡行动。

## 阵容与胜负

| 阵营 | 角色 |
| --- | --- |
| 好人 | 奇迹商人、预言家、女巫、守卫各一人，平民四人 |
| 狼人 | 普通狼人三人，狼王一人 |

默认闭眼屠边，有警长。所有狼人出局时好人胜。所有神职或所有平民出局时狼人胜。同一批出局同时满足双方条件时，好人胜。

## 夜间行动

奇迹商人 → 守卫 → 狼队 → 预言家 → 女巫 → 幸运儿 → 统一结算。女巫每夜最多使用一瓶本职药，全局不可自救。夜间攻击和反噬在所有夜间行动完成后统一处理，当夜受到攻击的商人和幸运儿仍可完成当夜行动。

### 奇迹商人与幸运儿

商人从首夜起可以等待，或选一名其他存活玩家赠予查验、毒药、守护之一。等待保留机会。整局只可成交一次，选择任何阵营都会用掉这次机会。

- 好人获赐后成为幸运儿，保留原角色、阵营和查验表现。平民仍计入平民。只有幸运儿本人收到技能和可用时机。
- 普通狼人和狼王都不会收到技能或通知。选中他们时商人因反噬出局，守护与解药只能处理同夜的狼刀。
- 商人收到的回执只确认所选技能和座位。首日默认先竞选警长再报死。夜间将出局的商人仍可在通报前报名、竞选或投票。报死只公布出局座位。

幸运儿可在获赐当夜使用技能，也可以跳过并留到之后的存活夜晚。获赐技能只可用一次，独立于本职行动和药品库存。

| 获赐技能 | 合法目标与效果 |
| --- | --- |
| 查验 | 选一名其他存活玩家，只向本人反馈好人或狼人。同一席的本职查验和获赐查验当夜须选不同人。 |
| 毒药 | 选一名其他存活玩家用毒。同一席的两次毒药当夜须选不同人，本职救人或停药后仍可用获赐毒药。 |
| 守护 | 选一名存活玩家，可守自己，只挡当夜狼刀。同一席的两份守护当夜须选不同人，次夜禁守本人前夜实际守过的全部座位。空守和跳过均无目标。 |

不同席可以选择相同目标，各自的回执只显示自己的选择。守卫和幸运儿可同守一人。有任一份守护挡刀，同时女巫对该刀口使用解药时，按同守同救判刀口出局。

### 狼王

狼王和普通狼人互认队友，共同密谈和提交刀票。只剩一名狼队成员时直接落刀。默认可以空刀、刀自己或刀队友。

狼王因放逐、狼刀或同守同救出局后，法官先判定胜负。符合条件且胜负未分时，法官只问狼王本人是否开枪。开枪带走一名存活玩家，公开狼王身份和中枪者。默认放弃开枪只回执本人。实际死因含毒或自爆时禁止开枪。

狼王可在本局开放的白天发言窗口自爆。按本项目规则，自爆亮出狼王牌并立即出局。警长报名和普通投票期间关闭自爆窗口，警上自爆后的延期与续投依房间规则卡。

## 记录与复盘

对局中，座位页面只显示该席可见的行动和回执，旁观页面显示公开记录。房主可以查看交易、私密行动和具体死因，导出原始上帝记录和视频剪辑稿。对局正常结束后公开复盘。本版型的边界判例见[奇迹商人版型实施方案](奇迹商人版型实施方案.md)。
