### 3.2 M-01：账号／区域作用域无法通过实际维护入口表达（P2）

- **定位：** `packages/session/src/model-maintenance.ts:28–32,76–88`；`packages/session/src/model-retirement.ts:23–26,37–38`。方案 §3.2 要求匹配适用账号／区域。
- **触发：** 同一模型、路由和协议，证据仅对一个账号、套餐或地区有效。实际目标只生成 routeId；`recordEvidence` 拒绝非空 accountScope／region，但接受两者省略的 authorization 证据。
- **影响：** 明确 scoped 的证据不能录入；省略字段后，分类器以 undefined 相等通过，预览不能机器核对账号／地区适用范围。即使证据挂在某个 modelId 上，也没有独立的范围字段说明探测针对什么账号／区域。这是契约缺口，**不是已发生跨账号误归档、未授权维护或全球停供误判的证据**。
- **最小修补／补证：** 在维护目标与记录中使用脱敏、可比较的账号／区域标识，明确 global 与 unknown 的区别；无法匹配的范围不得借省略字段获得确定分类。补作用域相同、不同、未知及旧记录兼容的离线用例。若产品决定首版仅支持全局证据，需明确缩小契约，并保持本次账号限定操作的独立说明。无需重新探测真实模型。
- **初审状态：** 当时未修补，原 `MODEL-RETIREMENT` 回到活动清单；已授权维护结果保留为历史事实，不回滚、不删除。后续修补及复审结果现见[归档](已解决问题与已实现改进.md#model-retirement)。
