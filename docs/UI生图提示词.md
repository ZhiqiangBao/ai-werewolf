## 约束

背景中心保持低干扰，桌子和座位由应用独立叠加。桌面带透明背景；座位号、身份、昵称与所有交互文字由程序绘制，避免把私密身份烘焙进图像。人物使用正面的二次元或绘本头像，各座位有不同的发型、服饰、表情与配色。

## 实际提示词记录

完整实际提示词、素材用途与参考图关系保存在 `design/ui-redesign/prompts.json`。该文件是最终生成记录，后续改图应从对应条目开始，保留构图、格数和透明底约束。

白天与夜晚不是简单滤镜，分别生成并与同款桌面的照明对应。六套人物保持同样的图集格数和正面头像构图，因此可在现场界面与离线视频中替换。
