# 工具 description 与 Schema 审计

> 2026-10-31：本轮逐项对照固定目录、实际行动工具、引擎校验与结算流程，覆盖全部15种游戏工具及内部 `ping`。上轮只重点强化了警徽工具，不等于已经完成这份全量审计。

## 发现并修正

| 问题 | 修正 |
| --- | --- |
| 退水说明声称竞选 PK 可用，引擎只在普通竞选发言提供 | 明确仅普通警上发言可退水，一次提交即结束本段发言。 |
| 女巫“不能毒已经用完的药”表述错误 | 分别说明 save、poisonTarget、两瓶药的资源限制与三种完整 JSON 示例。 |
| 自爆统一描述成白天发言即可使用 | 根据 speaker_only、interrupt、between_speeches 的开局设置说明窗口和工具，区分直接自爆与是否自爆的布尔询问。 |
| 票重硬编码为1.5/1 | 从开局规则生成普通票、警长票的实际权重。 |
| 参数 Schema 的布尔描述只有字段名 | 补充 true/false 含义，要求布尔值而非字符串。 |
| 警徽示例固定12号，对九人局并不适用 | 使用现有版型均存在的3号作为格式示例，并强调以本轮合法目标为准。 |
| 固定目录和轮次工具分别维护说明，可能漂移 | `Ctx.ask` 从对应固定目录获取说明，保留本轮动态参数限制。 |

## 逐项核对

| 工具 | 参数与使用条件 | 已核对的结果与限制 |
| --- | --- | --- |
| `speak` | content 非空字符串；轮到公开发言 | 警上、白天、PK与遗言；一次提交结束本段，内容公开。 |
| `vote` | target 整数；可弃票时允许 null | 放逐/PK目标、存活、自投规则和实际票重。 |
| `sheriff_signup` | run 为 true/false | 仅报名；全部提交后公开上警名单。 |
| `sheriff_withdraw` | content 字符串，可为空 | 普通竞选发言退水并结束本段；不声称支持竞选PK。 |
| `sheriff_vote` | target 当前候选整数，或允许时 null | 与放逐投票区分；依当前投票资格与候选名单执行。 |
| `set_speak_direction` | direction 两种英文枚举 | 号码增减、循环、警长末置；首位由引擎排定。 |
| `badge_dispose` | target 存活接收者整数，或 null 撕毁 | 不能给自己、不分阵营；实际按参数执行。 |
| `wolf_discuss` | content 非空字符串 | 仅当夜间轮到密谈，狼队私有；不直接产生刀口。 |
| `wolf_kill` | target 存活目标，或允许时 null 空刀 | 队友/自刀限制、同时落刀与合刀；空刀不计票。 |
| `wolf_explode` | 无参数，填写 `{}` | 存活狼人依本局窗口使用；夜间和投票不可用，后续结算归法官。 |
| `wolf_explode_decision` | explode 为 true/false | 仅专门询问时使用；多人选择由较小座位号执行。 |
| `seer_inspect` | target 其他存活玩家整数，不可 null | 可以重复查验，仅获阵营，不承诺查具体神职。 |
| `witch_act` | save 布尔＋poisonTarget 整数/null | 解药只救当夜刀口；药品耗尽、自救、双药、毒自己与目标存活限制。 |
| `guard_protect` | target 整数/null 空守 | 自守、连续守护和空守后的限制；只挡狼刀。 |
| `hunter_shoot` | target 其他存活玩家整数/null 放弃 | 由死因和当前法官许可决定能否发动；开枪公开身份。 |
| 内部 `ping` | ok 固定 true | 仅合成连通性测试，无游戏行动。 |

所有座位参数说明均强调真实整数座位号，不是候选列表下标；choice 给出英文值与标签，nullable 给出 null 的准确含义。当前说明示例只说明格式，不能替代动态目标与资源校验。

## 防止后续再次漂移

角色固定工具移至各 `roles/*.ts` 的 `RoleModule.tools`。三个模型协议从同一份 `ToolSpec` 生成说明与 JSON Schema；当前人类行动面板使用同源说明与动态候选参数。整局固定工具不随阶段、存活和资源变化，合法性由规则引擎校验。

回归检查包含全部15种工具的 JSON 示例与参数类型/枚举一致、完整对局中动态工具说明与目录一致、新角色通过注册自动提供固定工具，以及重复工具/流程不能静默覆盖。规则、可见性、死亡连锁等原有回归仍继续执行。

说明清楚只能降低误填，不能证明模型的内部意图。8号“思考写12、参数填5”的记录已单独核对；5是合法座位，结构校验无法判断模型究竟想选谁。程序不会根据思考文本擅自改成12，而是展示真实工具结果，并保留原始审计。详见[真实环境复查](视频素材与真实环境复查.md)。
