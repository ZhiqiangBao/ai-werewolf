# 视频制作 skill：首次接手 agent 的模拟走查

日期：2026-11-03。读者是接手制片任务、没有本项目聊天历史的 agent。本轮按用户要求模拟操作与判断过程，不额外制作真实整局视频。程序测试、既有样品及本轮 ASR 实验另列证据，不冒充这次走查实际生成了整片。

## 模拟任务与完成条件

输入为游戏仓库、`skills/werewolf-video/SKILL.md` 及“将最新已结束真实对局制作成完整上帝视角视频”的任务。agent 不预先知道目录、声线表、模型配置、旁白审核字段或本机 `D:/QWEN` 环境。先遵循目标仓库协作指南，再按 skill 取得所需知识。

完成指能够交付原话与事实有依据、字幕可读、声音与字幕时间一致、画面包含完整流程的视频，以及约定的封面、定稿文案和范围明确的检查记录。程序验证、独立转写、画面抽查和听感核对各有不同用途，不能互相冒充。

## 按实际执行顺序演练

| agent 当前目标 | 从哪里取得输入及操作 | 反馈与下一步 |
| --- | --- | --- |
| 确认工作区和工具可用 | skill 入口定位 `ai-werewolf` 仓库、根目录和 Node/pnpm；依赖按锁文件与已有安装授权准备；缺程序按 bootstrap 能力检查先更新游戏 | 缺仓库能力时在安装前明确停止；不能以安装包执行成功推断已有旧文件已升级 |
| 选择局、视角与范围 | `--prepare-only` 的 `latest` 选择结束局；读输出房间号、计划、可见事实；固定房间 ID 和独立项目目录。玩家任务另读 player-view 指南 | 无结束局就报告需要的输入；不能用含夜间私密信息的上帝素材改标签制作玩家版 |
| 在真实 TTS 前验证制作前置条件 | 依 preproduction/hardware 检查实际 FFmpeg/ffprobe、canvas、字体及美术；默认 ASR off，只有本次明确需要转写时才按 local-asr 指南准备对应服务及凭据 | 缺必要工具或 TTS 凭据时先修正，不等付费配音后才发现。未启用 ASR 时不把模型或 ASR 凭据列为制片前提；材料 `--check-only` 不会自动完成环境检查 |
| 将模板变成可用的完整脚本 | 读 plan/editorial-context 和授权原话；按 commentary 的锚点、写作步骤与完整示例整理开场、节点点评和收尾；保留真实原话，动作只据工具选择 | 未审核模板会被 preflight 拦住；agent 完成实际核对后记录规定的 review，不能只改通过字段 |
| 选定声音并检查材料 | 按 character-voices 指南及随包原始立绘提示词核对主题、各席外貌与默认声音；新配置逐席匹配，旧配置保留；法官和点评分声线；用固定房间执行 `--check-only` | `output/materials-check.json` 为 `ready: true` 才能进入真实 TTS。目录性别匹配不等于试听通过，换主题要复核已有配置 |
| 配音并审查声音 | 在既有授权范围执行 `--resume`；流水线做 TTS、原始波形、字幕与原稿对照和完整字时检查。声音存疑、新声线抽样或需要独立词边界时，才显式开启 ASR，可按 clip 选择 | 默认报告语义转写未检查；波形缺陷走定点修复；启用转写后的差异读报告并核对原音/原稿，只对明确核实的专名或字形设置本片别名，不自动改历史原话 |
| 处理字时停止点 | 英语/日语可验证 Qwen 响应的真实词边界，绑定原音/原稿/响应；英语本地或 MiMo 缺字时须明确请求 Qwen 补对齐 | 中文外部补对齐暂不支持，额外请求前失败；坏、过期或截断的对齐输入明确拒绝。不能均分时长、改标签或关闭校验蒙混 |
| 生成时间轴与完整画面 | 内容与字时通过后进入 timeline/render/preview/verify，检查实际编码器、报告与输出文件 | 编码失败按对应日志处理；重跑相同工作流复用有效配音和片段缓存，但仍重新做校验。`--resume` 不意味着跳过前序阶段 |
| 检查是否达到“还算可以” | 按 preproduction 的画面清单看昼夜、发言、票型、结局与字幕锚点；分别核对关键数字、否定、姓名/角色和漏增句，试听约定角色片段 | `matching` 或程序验证通过不代替这些检查；修正字体、布局或声音后按受影响阶段重做并再次验证 |
| 完成交付而非只交一个路径 | 按 cover 指南准备参考和定稿提示词，经已有授权的工具或明确人工交接取得封面；将定稿标题/简介保存为 `output/publish-copy.md` 并同步公开阵容及规则 | 完整上帝片约定的封面/文案缺失时报告缺项，不提前宣布全包完成。发布上传另需明确任务范围 |

## 本轮发现与处理的断点

1. **本地 ASR 首次启动缺少受信清单。** 只放模型并写 settings 不够；直接复制模型目录的 manifest 也可能因多出 README/LICENSE 被服务拒绝。已补 `asr:prepare` 离线注册工具与固定运行时清单副本，先核验已有模型/runtime，再创建服务所需控制文件；不会下载或启动模型，冲突清单默认拒绝，显式 `--replace` 先备份再原子替换。工具及受信 runtime 清单来自目标游戏仓库，不误称独立技能包自带。
2. **工具环境和 ASR 就绪检查可能拖到全部 TTS 后。** 已在文档的真实调用之前增加环境及语言路由的前置检查。`--check-only` 保持原有材料检查语义，文档不再暗示它保证 FFmpeg、在线鉴权或本地模型就绪。
3. **TTS 环境密钥与 Qwen ASR 凭据来源不同。** 文档明确区分 TTS 配置与 ASR 读取的项目加密模型库，提供不输出密钥的可用性检查及缺失处理，保留原主密钥，不自动换计费线路。
4. **续跑含义容易误解。** 已改为“重跑同一工作流，复用有效缓存并重新检查”，不暗示只从报错后的某阶段继续。
5. **全量 ASR 被误当作每次制片的必经步骤。** 根据用户确认，默认关闭额外转写，保留原稿对照及时间门禁；需要时可逐片开启，中英本地 Q8、日语在线 Qwen。
6. **声音与立绘存在可避免的错配。** 原始提示词已存在于设计目录，现随技能附带；六主题共 72 席按实际图集及目录性别/年龄感匹配，换主题不再假定同席性别相同。未做多声线真实试听，不将目录核对写为听审通过。

根 skill 同时补齐 agent 目标、起点、角色分工、成功标志及错误反馈到下一行动的映射。参考文档按各自目标承载具体步骤；原理、硬件边界及历史证据不机械套用操作模板。

## 验收边界

这次验证的是陌生 agent 是否能从输入找到下一步、识别停止条件、采取有依据的处理并到达约定交付；不保证外部额度、凭据、硬件或声线偏好天然齐全。缺少这些条件时，清楚交接和停止本身就是正确反馈，不要求 agent 猜测、擅自下载或重复外发。

本轮没有实际生成新的完整视频。离线准备工具和安装包入口另做针对性程序验证；ASR Q5/Q8 的实际材料、识别及性能结论见[量化对比记录](评估/Qwen3-ASR-1.7B量化对比.md)。英日声线与既有英语样品后续验收仍保持原有范围，不因模拟走查而写成完成。

本轮源码回归：127 个测试文件、991 项全部通过，TypeScript 检查通过；GGUF Python 单元测试 4 项通过。默认关闭 ASR 的合成玩家完整视频用例、逐片核对的零额外请求边界、六主题声线与旧配置保留均在测试范围。独立技能的 14 份 Markdown 引用检查无缺失，技能格式校验通过。这些程序检查不代替真实多声线试听或实际全局制片。
