## 已修复的六项问题

1. **前序消息没送完就允许行动。** 决策记录问话产生时的事件边界，座位的行动许可同时绑定决策编号。恢复积压消息时，前面的发言逐条旁听，最后一段发言和本轮邀请一起送达；收齐前序消息后才允许执行行动。
2. **旁听失败导致提前托管。** 旁听的接口错误、超时和错误工具调用均不消耗当前等待的行动。行动从实际发起请求时计时，AI 展示间隔不扣时。旧存档中只有截止时间、没有已送达行动许可的情况同样不能托管。
3. **失败轮次不进入后续上下文。** 每次助手调用及对应工具反馈立即追加到座位对话，包括第五次失败和请求失败。座位文件保存当前决策许可，服务重启后能恢复已经问到但尚未提交的行动，避免重复问话或卡住。
4. **系统提示与旁听指令冲突。** 系统提示改为：轮到自己且法官允许时必须调用工具；旁听时只在自己的上下文里简短回应。固定工具定义继续保留，狼人仍可按规则自爆。
5. **对局记录遗漏法官问话。** 所有行动问话默认记录给行动者；投票等公开问话记录为公开事件。上警、女巫刀口与用药、狼人并列刀口与重选合并为一次问话。记录受众保持信息隔离，上帝视角可查看完整内容。
6. **放逐票型与结论拆开播报。** 票型带上出局、PK 或无人出局结论，进入模型和页面时只播报一次。出局、白痴翻牌等事实仍保留供复盘；已包含在合并播报里的事实标记为 `payload.announced=true`，不会重复生成上下文或页面消息。

座位设置现在提供「跟随模型、关闭、轻度、标准、深度」五个按钮。默认继续跟随模型；强制思考模型禁用关闭按钮，没有独立轻度档的接口禁用轻度按钮。更换模型时仅保留兼容档位，配置会保存并用于「同配置再来一局」。

档位根据模型和入口映射：Qwen3.8 的已知正式型号使用原生 `reasoning_effort=low/medium/xhigh`；较早 Qwen 和支持预算的百炼 GLM/Kimi 使用思考预算 1024/4096/16384 token；百炼旧版 DeepSeek V4 Pro 只提供 `high/max` 两档，GLM5.3 使用 `low/high/max` 且不能关闭。仅传力度或预算中的一种，不改变正文长度、系统消息和固定工具 Schema。未知模型不启用未经确认的强度档位。映射参考 [百炼 Chat API](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)、[百炼深度思考](https://help.aliyun.com/zh/model-studio/deep-thinking)、[DeepSeek](https://api-docs.deepseek.com/guides/thinking_mode/) 和 [GLM](https://docs.z.ai/api-reference/llm/chat-completion) 文档。
