# 音频播放恢复实施记录

日期：2026-11-03。

## 播放与行动语义

浏览器只处理当前凭证获得的投影。自动朗读启用后，新发言按序进入独立队列；失败保留当前项和后续项，自动订阅保持开启，用户选择可用来源后明确点击「重试当前发言」。切换来源会停止旧驱动并使晚到回调失效；来源删除也保留待播内容。主动关闭自动朗读或点击「停止并清空队列」才明确丢弃当前及待播项。

手动重听插播一条，不清空自动队列；成功播完后会移除队列中相同序号的待播项，失败或被新决策打断不会将其当作完成。自动队列原先处于用户暂停状态时，手动插播结束或被决策变化打断后仍保持暂停，直到用户继续。来源或音色变化会从当前项重新播放；暂停和真人行动让行之后也可能从当前项开头重新播放，不保证中断点续播。

仅当房间运行中且未暂停、当前访问者是该席真人控制者、任务尚未提交时，行动可用后自动朗读让行。若 `actionAvailableAt` 在未来，先按预告状态播放，到时由本地定时器重新评估，无须等待新推送。手动重听可临时覆盖当前决策的让行，界面提示行动倒计时继续；手动项结束或决策变化后恢复让行。服务端行动截止时间与超时规则没有更改，音频不延长时间。

## 验证范围

使用实际网页调用的 `SpeechPlaybackController` 和可控假播放驱动，覆盖失败时已有两条后续发言、失败后新事件、相同投影重连、暂停期间返回、来源删除和切换、旧驱动晚到、手动重听及去重、行动预告到时、决策变化、真人权限条件和控制器隔离。视图加载按房间和凭证建立独立作用域，切换时立即隐藏旧快照，旧请求及旧 SSE 回调不得发布到新作用域；使用实际加载器和作用域回调验证迟到的成功、失败和更新事件。播放输出既有测试同时运行；未调用真实 TTS 或浏览器音频接口。当前环境中的 Corepack 入口尝试联网失败，因此直接调用项目已安装的 Vitest、TypeScript 和 Vite 入口完成等效检查。
