# 对局视频制作工作流：配音驱动画面

更新：2026-11-01。已接入 Qwen TTS、字幕时间戳、事实回放和离线合成；不新增实时录屏功能。

## 这次跑通的流程

对局存档 → 上帝视角剪辑稿 → 人物声音表与上帝台词 → 逐段 Qwen TTS → 实际音频时长与逐字时间戳 → 回放状态 → 1080p 视频。

以真实对局 e6220f1238 为首版项目。全部玩家公开发言、遗言与狼队密谈保持原话；查验、用药、守护等动作配音只能口述实际工具选择。法官保留夜间问答、投票邀请和结果，警长回答起点/方向后视频直接进入发言，不再重复点名。关键点评使用独立的 `after`，接在事实播报之后。详细备料和润色步骤见 `skills/werewolf-video/references/preproduction.md`，批量 TTS 及其他服务接入见 `references/tts-batch.md`。

## 本次实现

| 环节 | 实现 |
| --- | --- |
| 导出 | `packages/session/scripts/export-video.ts`，只读本地存档 |
| 剪辑 | `scripts/video/editorial.ts`，原始事实流保持不变 |
| 真实性检查 | `integrity.ts` 在配音前核对原话和工具选择，拒绝编造玩家对白 |
| 主持 | `hosting.ts` 补齐询问、选择、确认、闭眼与投票，动作转述有来源标签 |
| 声音 | `scripts/video/voices.json`，12 位人物、法官、上帝解说分别固定音色 |
| TTS | `scripts/video/qwen.ts`，仅使用 Token Plan 端点，读取已有本机配置或环境变量，密钥不写入产物 |
| 缓存 | 按文本、模型、音色、语速、指令及种子计算键；成功音频可复用 |
| 时间轴 | `scripts/video/timeline.ts`，读取真实 PCM 样本数和提供方逐字时间戳 |
| 画面 | `scripts/video/replay.ts` 与 `scene.ts`，从原事件恢复昼夜、存活、身份、上警、退水、警徽、票型 |
| 规则卡 | 全部实际身份的完整技能循环滚动，跨发言延续进度；投票卡按行数收紧并放大数字 |
| 动画 | 根据配音产生真实声波；当前发言座位高亮，使用同一套游戏美术 |
| 合成 | `scripts/video/render.ts`，分段编码、断点复用、合并主音轨与章节 |
| 检查 | `scripts/video/verify.ts`，核对原话、事实、终局、字幕、帧数、章节与音画时长 |
| 压缩 | 默认另存 `latest-match-share.mp4`；1080p H.264 CRF 28、AAC 96k，母版保留 |

时间基准为 24kHz 音频、30fps，每帧正好 800 个样本。每段保留少量独立的编辑停顿并补齐至帧边界，拼接不会累计漂移。音频作音量归一与峰值限制；画面不使用模型网络等待时间。

字幕来自最终配音的逐字时间戳，按标点和阅读长度分行。缺少时间戳时会停止并报错，不伪造对齐。保留原文和实际朗读文本，座位号、票数和箭头只作发音规范化。

  timeline.json                 实际声音时间轴
  subtitles/captions.ass        精确时间字幕
  subtitles/captions.srt         通用剪辑字幕

这些本地对局及媒体产物在忽略目录 data 下，不把房间访问令牌或 API 密钥提交进仓库。

## 再次制作

需要系统提供 FFmpeg / FFprobe；画面依赖已纳入项目。以下在项目根目录执行，首版默认为 e6220f1238：

```powershell
pnpm video:export --room=e6220f1238
pnpm video:tts
pnpm video:timeline
pnpm video:render
pnpm video:verify
```

制作其他对局时先设置 `$env:VIDEO_ROOM`，导出对应存档，再调整声音表与可选的 `narration-房间号.json`。编辑稿严格检查房间号，不能误用本局点评到另一局。

更改一段配音后，从 TTS 开始依次重新执行即可；未变化的音频与画面片段复用。任何阶段中断都不需要重新开始对局。

编码默认单路，限制线程与缓冲，降低本机内存占用；硬件编码失败会回退软件编码。FFmpeg 路径可用 FFMPEG_PATH / FFPROBE_PATH 指定。首版使用 Windows 字体和日式校园人物；更多画幅、人物主题与本地 IndexTTS 适配可在此基础上扩展。

## 当前边界

这是完整上帝视角，包含夜间私密信息。真人玩家的实时视角仍由服务器权限控制；如果将来导出玩家或闭眼版视频，需要先按该视角过滤素材，不能沿用本次完整事实流直接显示。

首版保留所有玩家原话，因此约 43 分钟；进一步压缩成节目版时，应另存剪辑选择表，保留每个节选的原事件与文本范围。第一版没有额外背景音乐，以便检查配音、字幕与事实时序。
