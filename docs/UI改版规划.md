# UI 改版：月影森林议事厅

更新：2026-11-01。当前状态：已实施，进入真实对局视频制作验证。

## 最终美术方向

采用二维插画与绘本式游戏美术。森林村落、青绿绒面圆桌、柔和金色装饰共同构成游戏舞台。背景、桌子、人物与状态独立叠加。

用户确认后的方案包括：

- 白昼与夜幕各有一套生成的背景和透明桌子，游戏根据阶段切换。
- 首页提供白昼、夜幕选择，保存浏览器偏好。
- 六种人物主题可切换：童话绘本、日式校园、中式古风、剑与魔法、现代都市、未来科技。
- 每套 12 个不同人物，共 72 个头像，头像风格选择可保存。
- 桌面座位沿实际桌面的椭圆排布，手机使用竖向桌面与独立角度。
- 上方 11、12、1、2 号向外移，侧面发言提示朝桌内放置。
- 头像左下角显示号码，右下角显示当前视角允许知道的身份，下方仅显示自定义昵称。
- 创建房间时可填写昵称，为真人参与保留入口。

## 状态与身份

发言提示包含麦克风、声条和呼吸光环；暂停和减少动态效果设置会受到尊重。上警、退水、警徽、存活、出局与技能目标分别有标记。

| 视角 | 可展示身份 |
| --- | --- |
| 上帝 | 全部身份 |
| 玩家本人 | 自己的具体身份 |
| 狼人 | 自己与已知狼队友的狼人身份 |
| 预言家 | 自己，以及实际查验对象的好人/狼人结果 |
| 观战 | 不显示私密身份 |

扩展的身份知识支持阵营结果与具体身份两种类型。现有预言家只返回阵营结果；未来具有精确查验能力的角色可通过角色模块返回具体身份。详情、提示与辅助标签使用同样的权限规则。

## 验证

已检查桌面与手机宽度、六种人物主题、昵称、暂停状态及身份权限。隔离测试房间不修改真实对局。上帝、预言家、狼人、普通玩家和观战的实际界面均检查过；服务器投影视图也有权限测试。

视频制作复用这些原画与人物，用对局事实离线重建上帝画面。现场界面保持真实行动状态，视频中的波形按最终配音生成，不新增实时录屏功能。见《对局视频制作工作流》和《上帝旁白设计》。

## 后续改进：真人与模型统一为 Agent

2026-11-01 记录，暂不实施；当前优先完成视频样品和制作 skill。

真人座位也抽象成 Agent。模型与真人只使用不同的输入适配器：模型接口返回工具调用或结构化 JSON；真人点击按钮、提交输入框文字，或确认语音转写。所有输入最终映射为同一种结构化工具调用 `ToolCall { tool, args }`，携带相同的座位和决策标识，交给同一个法官引擎校验与执行。按钮行为直接生成与模型调用等价的 JSON，不另设真人规则或第二套处理流程。

输入框文字或确认后的语音转写作为 `speak` 的真实参数；其他按钮提交对应工具名及参数。语音识别不得替玩家润色或补写观点，最终提交的文字和工具选择进入同一套真实记录。

可加入语音播放，将模型的真实发言文字转换为该角色的声音，真人以接近传统狼人杀的方式听取对话。模型接收的仍是带来源标记的文字发言和工具结果；语音仅作为真人端的输入/播放渠道，沿用座位原有的信息可见性。

工具经法官接受、执行并返回结果后，再生成相应的界面或语音反馈，这是模型与真人共用的现有处理原则，不是专门为真人增加的步骤。语音转写、播放与实际行动的耗时分别管理，避免额外压缩玩家的决策时间。
