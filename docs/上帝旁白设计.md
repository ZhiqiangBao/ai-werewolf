# 最新一局的上帝旁白设计

更新：2026-11-01。目标是让观众跟上推理、看清反差，玩家的发言仍是主体。

## 参考了什么

在浏览器播放器抽看十月枫林尽染的[《狼踩狼，通灵师的噩梦》上帝视角](https://www.bilibili.com/video/BV1JGZcBjEBL/)开场、中段和结尾，并查看内嵌字幕：

- 夜间段用短行动播报推进，并穿插针对当前玩家的简短点评。
- 玩家长发言占主要篇幅；画面用箭头指向对应座位，同时显示发言文字。
- 上帝视角持续显示身份；夜间和白天有明显视觉区分。
- 结尾另有带人物色彩的内容，而不是单纯重复系统结算。

以上是对实际画面和字幕的观察，未取得作者的工程文件，也没有确认其具体 TTS 型号。下面的台词、音色与剪辑方案是结合本项目真实对局所作的原创设计，不复制参考视频的台词或声音。

## 声音分工

| 声音 | 内容 | 表演方向 |
| --- | --- | --- |
| 法官 | 昼夜、行动、死亡、投票结果 | 简短、清晰、公正 |
| 上帝解说 | 开场、关键转折、简明复盘 | 知性自然，带一点看懂局势的兴味 |
| 玩家 | 真实发言、遗言、狼队密谈 | 每个座位固定独立音色，按性格设置语气 |

本局配置在 `scripts/video/voices.json`；使用 Qwen Token Plan 的 `qwen-audio-3.0-tts-plus`。12 位玩家分别有自己的音色，法官和解说也分开。

## 哪些上帝发言剪入，哪些省略

| 节点 | 剪入内容 | 画面承担的信息 |
| --- | --- | --- |
| 开场 | 板型、上帝视角、两位主要人物 | 全桌身份与昵称 |
| 夜间 | 实际守护、刀口、查验、用药 | 技能目标与相关座位 |
| 上警 | 上警者和起始发言者 | 上警、退水、顺序标记 |
| 选警、放逐 | 胜出票数或目标，一句局势点评 | 全部投票人、权重、弃票 |
| 警徽移交 | 谁交给谁，必要的阵营反差 | 警徽归属变化 |
| 守中狼刀 | 平安夜和守护效果 | 守护目标与刀口重合 |
| 终局 | 胜负、几次关键转折 | 身份与存活结果 |
| 重复流程 | 省去完整警下名单、逐一点名、重复“胜负已分”等 | 事实仍保留，画面回放不删 |

不把接口等待、错误、托管诊断和 Agent 问话配进成片；不替玩家编造内心想法，也不把上帝知道的身份说成玩家已经知道的事。

## 已写入本局的例子

一号当选：

> 警下八票，全部给到一号。大老师这一轮，真把大家都说服了。接下来就看十号，能不能把自己的预言家身份讲清楚。

二号守护一号：

> 雪乃这晚守了一号。大老师不仅拿着警徽，连守卫的保护也一起拿到了。

警徽交给四号：

> 警徽给了四号。大老师人走了，队友还接着带队。

这些点评只在原事件已经发生时出现。第四夜的守护成功在夜间结算以后才解释，投票前不提前宣布结果。
