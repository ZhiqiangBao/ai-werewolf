## 实现与证据

播放改动由实际 Hook 使用的控制器承担，区分自动订阅意愿、失败、用户暂停、行动让行和手动插播。房间或凭证改变时清空旧权限上下文；`ViewLoader` 与 SSE 回调另加作用域边界。后端行动时限、引擎规则与工具协议没有因播放延长。操作路线见[发言朗读](发言朗读.md)，具体范围见[播放实施记录](音频播放恢复实施记录.md)。

服务层分开处理等待者完成和物理任务释放。HTTP 对局朗读及试听都桥接断连；取消中的同文任务拒绝新订阅并要求稍后重试，避免旧任务与新任务同时写缓存。Qwen 缓存关键边界检查取消；已经开始的文件操作和跨目录缓存复制不能强制撤回，完整有效缓存可保留。忽略信号的第三方模块仍可能占槽或导致关闭超时，不把本地 abort 说成提供方已停止生成或计费。见[取消实施记录](共享合成取消实施记录.md)。

本轮模型只用已授权的固定项目型号和合成投影。每个公开变体先用引擎生成两组不同隐藏真相，并断言本席投影、消息、工具完整相同。Astra 在不见条件标签、档位、底牌、时延和候选系统段的材料上固定评分，之后由主代理揭盲汇总。48次逻辑调用全部成功且引擎接受，未补样、未追加追结论；没有保存或公开思考正文、密钥和真实对局。完整合成输入、实际行动工具输出、响应元数据和冻结评分见[模型复核报告](评估/MODEL-UNSUPPORTED-CERTAINTY评估.md)及[证据](评估/MODEL-UNSUPPORTED-CERTAINTY数据.json)。
