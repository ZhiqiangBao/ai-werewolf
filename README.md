# AI 狼人杀

十二个座位，有的后面坐着人，有的后面接着大模型。法官是规则引擎：刀口、查验、解药与毒药、守卫、发言顺序、投票、警徽和胜负都由引擎判决。每个座位只能看到自己该看的信息，模型收到的提示词和这个座位的页面是同一份。

仓库：<https://github.com/ZhiqiangBao/ai-werewolf>

完整规则见 [docs/需求说明书.md](docs/需求说明书.md)。

## 下载到运行

需要 Node.js 22 或更新版本。pnpm 用 Node 自带的 Corepack 启用。

```bash
git clone https://github.com/ZhiqiangBao/ai-werewolf.git
cd ai-werewolf
corepack enable
pnpm install
pnpm dev
```

`corepack enable` 在 Windows 上若提示权限不够，改用 `npm install -g pnpm`，然后再执行 `pnpm install` 和 `pnpm dev`。

看到 `AI 狼人杀已启动` 后，浏览器打开 <http://127.0.0.1:5173/> 。

已经有这份代码时，在仓库目录里执行 `pnpm install`，然后 `pnpm dev`。

生产模式先构建网页，再启动服务：

```bash
pnpm build
pnpm start
```

## 怎么玩

1. 打开首页，点 **创建房间**。浏览器会进入房主页。房主是上帝，能看到全部身份。
2. 选版型。标准局是 **九人经典** 和 **十二人预女猎守**，默认屠边、竞选警长。**十二人预女猎白** 用白痴换掉守卫，是扩展示例。
3. 准备模型。在「模型」里添加一次：名称、接口地址、密钥。装了 Qwen Code 的话，`settings.json` 里写好的模型会出现在同一份名单里，不用再填一遍。
4. 每个 AI 座位用下拉框从这份名单里选一个模型，点这一行的 **测通**。留在「模拟玩家」的座位不联网，也能打完一局。座位也可以改成 **真人**。
5. 展开 **邀请链接**。房主链接留给自己；观战链接只看公开信息；每个座位链接发给对应的人。链接里带有凭证，等同于身份。
6. 点 **开始游戏**。

对局进行中，房主可以：

- **暂停**：停在当前这一步。暂停后可以 **单步**（只让模型走一步）或 **继续**。
- **终结**：取消还在进行的模型请求。这一局记为流局，无胜负，不公开身份，也不做复盘。

关掉浏览器页面，服务还在跑，模型还会继续被要求行动。要停掉这一局，回到房主页点 **终结**。

发言、遗言和狼队密谈限时 3 分钟。放逐投票和警长投票限时 90 秒。

上帝页能看到每个模型正在写的内容，座位页只能看到自己的。思考是虚线浅底，模型另写的正文是实线色块，公开发言仍是对局记录里的气泡。这些思考和正文只在页面上往外长，不会写进任何座位的提示词。

结束后可以 **同配置再来一局**。密钥、房间和对局记录写在 `data/`，不会进入仓库。

## 版型

| 版型 | 身份 |
| --- | --- |
| 九人经典（预女猎） | 狼人 ×3、平民 ×3、预言家、女巫、猎人 |
| 十二人预女猎守 | 狼人 ×4、平民 ×4、预言家、女巫、猎人、守卫 |
| 十二人预女猎白 | 狼人 ×4、平民 ×4、预言家、女巫、猎人、白痴 |

## 环境变量

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `PORT` | `5173` | 端口 |
| `HOST` | `127.0.0.1` | 监听地址 |
| `WEREWOLF_DATA` | `./data` | 房间、密钥和添加的模型 |
| `WEREWOLF_QWEN_SETTINGS` | `~/.qwen/settings.json` | 从这里读取已经写好的模型 |

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `pnpm dev` | 开发模式，接口和网页在同一端口 |
| `pnpm test` | 规则、可见性、会话和模型适配测试 |
| `pnpm typecheck` | TypeScript 检查 |
| `pnpm simulate` | 用模拟玩家把一局跑完 |

## 目录

```text
packages/protocol   行动、事件、投影的数据结构
packages/engine     规则引擎。不访问网络、数据库和模型
packages/llm        模拟玩家与 OpenAI 兼容适配器
packages/session    房间、事件日志、凭证和自动推进
apps/server         HTTP 接口，并托管网页
apps/web            座位页、观战页和房主上帝页
docs                需求说明书
```

增加身份时，在 `packages/engine` 注册身份模块，再把它放进版型的身份列表。
