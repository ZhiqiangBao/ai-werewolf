# AI 狼人杀

网页版狼人杀。每个座位可以交给真人，也可以接入一个大模型。法官是确定性规则引擎：身份、夜间结算、发言顺序、投票、警长和胜负都由引擎判决。每个座位的页面和模型提示词使用同一份投影，只能看到该身份该看的信息。

完整规则见 [docs/需求说明书.md](docs/需求说明书.md)。

## 运行

需要 Node.js 22 或更新版本，以及 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开 http://127.0.0.1:5173/ 。创建房间后，房主配置版型和每个座位，再开始对局。

模型先加入名单，再给座位选。添加时填写名称、接口地址和密钥；密钥只写在 `data/models.json`，不会进入仓库、提示词或导出的玩家记录。如果安装了 Qwen Code，`settings.json` 里写好的模型会自动出现在同一份名单里。每个座位从这份名单里选择，并用「测通」检查能否调用。不选模型时，座位可以使用内置模拟玩家打完整局。

生产模式先构建网页，再启动服务：

```bash
pnpm build
pnpm start
```

可选环境变量：`PORT`（默认 `5173`）、`HOST`（默认 `127.0.0.1`）、`WEREWOLF_DATA`（默认 `./data`）、`WEREWOLF_QWEN_SETTINGS`（默认 `~/.qwen/settings.json`）。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `pnpm dev` | 开发模式，接口和网页在同一端口 |
| `pnpm test` | 运行规则、可见性、会话和模型适配测试 |
| `pnpm typecheck` | TypeScript 检查 |
| `pnpm simulate` | 用模拟玩家把一局跑完 |

## 目录

```text
packages/protocol   行动、事件、投影的数据结构
packages/engine     规则引擎。不访问网络、数据库和模型
packages/llm        模拟玩家与 OpenAI 兼容适配器
packages/session    房间、事件日志、凭证和自动推进
apps/server         HTTP 接口，并托管网页
apps/web            座位页、观战页和房主上帝页
docs                需求说明书
```

网页不自己结算。增加身份时，在 `packages/engine` 注册身份模块，再把它放进版型的身份列表。
